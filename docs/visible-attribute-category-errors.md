# Does a visible state help on real cross-class Semantic Dot errors?

Retrospective follow-up fixed after the within-class analysis. AUC for an attribute can be high even if the attribute carries no useful information for deciding which RGB candidate has the query's category. Test this distinction directly on the same annotated sketch IDs. Use the full gallery for each split and the original Semantic Dot scores. Freeze the highest-scoring right-class and highest-scoring wrong-class photograph per sketch before reading any of their attribute scores. This yields a definite repair/damage count relative to the baseline. The true candidate may be the original source, as in the official gallery.

Ground the diagnosis in the isolated pair of texts previously frozen for each class. Measure two evidence sources. The first uses the single sentence for the observed visual state. The second subtracts the score of its opposite sentence. Evaluate each with the actual state supplied after annotation and with the state chosen by the frozen sketch encoder. Use the same pair of candidate photos for every comparison. Compare accuracy with the exact expectation under uniformly permuting the observed state labels among the included sketches **within each class**. This preserves the prevalence of both states and all class-specific vocabulary. An advantage would indicate that the state of the specific sketch, rather than its class's usual state, helps to choose between those two real gallery candidates.

Use all classes with both jointly observed states as the primary evaluation population. Also publish all jointly definite subjects, all sketches with a definite label, and separate counts for baseline errors and baseline correct cases. Report sample size and balanced class uncertainty. Use actual KD per-query AP and P for the full gallery as a secondary descriptive readout. For a fixed class-specific text bank the act of permuting complete text choices within the class leaves the multiset of full-gallery rankings unchanged, hence leaves aggregate class mAP and precision unchanged. Verify that invariance by an explicit permutation. Sketch-dependent candidate pairs can still distinguish true from shuffled labels. All class-specific texts and their two opposite states are manually supplied here. None of these rows is a deployable zero-shot method.
