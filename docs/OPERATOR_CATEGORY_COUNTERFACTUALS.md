# Does the shared gallery structure actually predict the requested category?

A common orientation of operators could arise from ordinary covariance in photo features. After selecting the retrieval parameters, break the association between each gallery photo's whole-image measurement and its regional views. Apply one fixed derangement across the reference photos. A second control cyclically reassigns whole-image measurements only among members of the same unsupervised visual cluster. The regional geometry, source query, candidate images, folds, and multisets of whole-image measurements are identical within each comparison. A globally shuffled association producing the same gain would weaken attribution to the connection between global and regional content. Preservation within coarse visual neighborhoods would be consistent with a population-level effect. These tests are diagnostic and never select a seed or a new TU-Berlin configuration.

In a separate readout, disclose category membership only for the photos in the independent measurement partition, after the deployment rankings have been fixed. Evaluate how well that exact class signal can be decoded on the disjoint candidate partition for each category. The gallery operator remains independent of the labels. A class signal that can be decoded across photos although real sketch retrieval remains weak points to the transfer from the sketch as a distinct failure point. The class-oracle condition uses labels and is ineligible for deployment or benchmark comparison. Report exact class-level AP through the original evaluator, pair-order probabilities, and per-class measurements. Compare three prespecified ways of partitioning the same unlabeled photos while keeping the real query parameters fixed.
