# Two-description pilot under public noun renaming

Approved scope is the two complete exploratory Sketchy splits on Kaggle. Freeze the following construction before measuring any retrieval results. The source vocabulary remains the original 601 public Open Images nouns. The additional resource is Princeton WordNet 3.0, the installed NLTK archive with SHA-256 `cbda5ea6eef7f36a97a43d4a75f85e07fccbb4f23657d27b4ccbc93e2646ab59`. Use frozen OpenAI CLIP ViT-B/32, no gradient, seed 42 and no other sketch at prediction time. No tuning or TU run.

1. Collect **all noun synsets** having an exact Open Images lemma after case, whitespace, underscore and hyphen normalization. Each synset gets a single public head, the lowest original vocabulary index if there are synonyms. Within its gloss replace mentions of any of its own lemmas with “object”, including noun plurals. Report missing names, full coverage, all public IDs for each synset, and occasional unusable definitions.
2. Nominate two alternative meanings from the complete bank of anonymized definitions, using the normalized mean of the two frozen sketch views against drawing-template descriptions. The second must have a different public head. This is a fixed, small experiment on the inversion of one sketch. It does not consult photo scores, benchmark classes or the Semantic Dot rank. The same two hypotheses are supplied to every selection control.
3. For the actual comparison redact the lemmas of **both** senses from **both** glosses. Let A and B be the two descriptions and a and b their public heads. Take the image-text score difference d = f(a,A) − f(b,B) using natural attachment, and e = f(b,A) − f(a,B) using swapped names. A decision is certified only when d and e have the same strict sign. On certified queries select the corresponding description. Report the coverage and compare all controls on those identical queries. For a single all-query measurement keep the anonymous-definition choice whenever certification abstains. This fallback measures the added value of the intervention against the definition baseline; it is reported explicitly. With two alternatives forcing a maximin choice on abstentions is algebraically equivalent to choosing by d+e, so that is outside this pilot.
4. Controls choose between the same meanings using the names alone, the anonymous definitions alone, or the original attachment without a swap. For an additive model the margins are D+N and D−N, where D and N are the anonymous-definition and name-only margins. Check whether it predicts the observed certification. Under an additive model, every certified decision agrees with the anonymous description. Also count decisions changed relative to that baseline.
5. Read each selected **anonymous** definition with the target photo prompt and query all native RGB image embeddings directly. Evaluate both alternatives once per query with original KD-SBIR, then reuse the relevant official AP/P rows for the selection arms. A separate direct name-only control uses the best unmodified public name under the sketch prompt and queries RGB with its photo-template name. Also report the original Semantic Dot and the label-informed, metric-specific best of the two candidate definitions. Candidate nomination can limit the reachable mAP.
6. For each query, after encoding and ranking, use labels to retrieve the original Semantic Dot's highest-ranked true and false photos. Compare the same pair under every selected definition. Report repairs, damage, ties, and the subset where the erroneous winner shares the sketch's word but the best true photo has a different word. Run this audit on all queries, including the cases where the baseline was already right. Each shard contains alternating original query indices and a complete gallery.

The gate for development requires improved all-query mAP over the anonymous definition on **both** exploratory splits and an improved balance of corrected versus damaged matched pairs among certified decisions against that same control. Report uncertainty grouped by class and any shortfall against the +4–5 point target above Semantic Dot. Stop when evidence fails these controls. Class names are available only for evaluation. No labels enter gloss preparation, candidate nomination, text swaps or selection.
