# Two tests of what frozen CLIP loses across visual domains

The primary question is whether CLIP's response to a change of depiction carries comparable **content-specific** information in its image and text encoders. A global domain direction or an object name alone may predict part of an apparent effect. Both need explicit controls. This is a diagnostic on existing representations. Class names, labels, source IDs and other drawings are available to the evaluator only. There is no proposed retrieval score in this experiment.

## Actual retrieval errors

Use every Sketchy query with its two archived native visual leaders on the complete gallery after excluding its own photograph. Candidate A is the highest scoring photo of the true class and B is the highest scoring photo of another class. On precisely these endpoints compare the native reader and the archived Semantic Dot reader. For each query from class A take **all** independent drawings of class B, omitting any whose own source is one of the two candidates. Give each foil source photograph equal weight and each of its drawings equal weight within that source. Use a third, unrelated class as a negative control by averaging all other classes equally, with equal source and drawing weights in each. The negative-control sketch need not depict either target.

Let m(q) = s(q,A) − s(q,B). Report the probability that m(q_A) exceeds m(q_B). This is the test for which of the two assignments of two queries to the fixed photos has the higher total score. Every additive query bias and every additive candidate bias cancels. If m(q_A) ≤ m(q_B), no query-independent addition to the score of each photo can make both strict pair decisions correct. These are two-query diagnostic comparisons and have no role in the deployed retrieval protocol. Report native errors and correct leaders independently. Average first by query source, then uniformly across classes. Compare the foil to the unrelated-query control and report class-bootstrap intervals. Include results excluding the four classes common to both splits, with rival classes and foil pool restricted as well. Candidate selection stays on the original full gallery.

## Do text changes predict real image changes?

Measure sketch → photo on every real drawing/source identity. For each source photo, first average its drawings and then compute photo minus drawing in the native CLIP output. Give every source equal weight within its class. Independently apply a second manipulation to every existing gallery photo, rendering a grayscale and an RGB version from the same raster. Run both through the same frozen image encoder, preprocessing, order and precision. Fit no image model. Grayscale → RGB tests a controlled appearance change with fixed subject, composition and dataset. It does not replace a benchmark on another natural domain pair.

For the diagnostic only, take the published class names, replacing underscores with spaces. Without selecting names or prompts, encode four descriptions of each name with a 2 × 2 design. The factors are depiction (drawing / photo or black and white photo / color photo) and article (a / the). Average over articles to obtain a depiction contrast, average over depictions to obtain an article contrast, and use the mean of all four as a control for object meaning.

Predict the mean visual change in a held-out class using the mean of the other classes, then allowing one shared scalar multiplying the centered meaning vector, then a second scalar multiplying the centered text depiction contrast. These scalars are descriptive regression coefficients over CLIP coordinates, estimated solely on the other classes. Record squared prediction error against the meaning-only control, signed coefficients, replacing depiction by article, and the distribution from 999 seeded permutations of the noun assignment of the depiction contrasts. Bootstrap increments by class. Classes, not individual drawings, are the independent units of these checks. Evaluate both complete exploratory Sketchy splits and disjoint classes. Also freeze the scalar coefficients from Ext-1 and evaluate Ext-2 classes absent from Ext-1. This test uses real class names to give the linguistic hypothesis its best case, not a permissible inference method.

Positive evidence for a literal same-direction mechanism requires the extra depiction contrast to reduce squared error beyond the meaning control, beat the 95th percentile of shuffled assignments, and have a positive median coefficient on both Sketchy splits. The grayscale control tests the scope of that inference. A negative result does not establish that all possible image and language relations fail. No score corrections, new retrieval method, search over prompts or tuning against TU-Berlin occur here. Both Sketchy splits have been studied before. If reporting a TU check, freeze source coefficients and the interpretation from Sketchy first. TU sketch and photos lack the same source pairing as Sketchy. State that distinction in the report.
