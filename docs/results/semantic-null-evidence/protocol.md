# Testing a query-specific background model for CLIP word evidence

The covariance-matched orientation experiment showed that native alignment with text matters. It does not imply that subtracting a null expectation improves retrieval. We test that separate hypothesis here inside the global semantic retrieval module alone.

In the eigenbasis of unlabeled gallery covariance write a = Vᵀ(x−μ) for one sketch view, b_w = Vᵀt_w for a normalized public source prompt, and s for the native CLIP scale. Under the null take independent coordinates Y_j distributed as N(0,a_j²). This is the maximum-entropy continuous law with zero mean and the specified diagonal covariance. It preserves per-coordinate second moments in expectation. For word w the null log moment of the centered image response is exactly K(x,w) = log E[exp(s Yᵀb_w)] = ½ s² Σ_j a_j² b_wj². Subtract K from the ordinary CLIP logit before the softmax. The exponential of the corrected centered response has expectation one under this null. The original CLIP logit at the gallery mean supplies the word intercept. The Gaussian assumption is a modeling choice. The scoring procedure uses no sampled random directions or trained parameters.

The primary intervention corrects sketch views only, leaving the target bank and RGB graph untouched. Compare the native channel with the query-specific correction, its pooled-gallery counterpart (replace a² by gallery eigenvalues), a word-identity control (reassign penalties by a random permutation within strata of 64 adjacent gallery-mean source logits), and native logits adjusted only to match the primary posterior's entropy separately for each view. Report the secondary correction K(x,w)−E_gallery[K] to isolate the query-specific deviation. Slots 1,536–2,303 of the seed-42 permutation define 768 queries per Sketchy split with full galleries. Advancement requires positive mAP relative to native, permuted correction, and entropy-only on both splits after standard diffusion. Separately test whether query-conditioning improves on the pooled correction. Report direct scores, precision, class-level intervals and posterior entropy. No TU run based on a failed fixed intervention.
