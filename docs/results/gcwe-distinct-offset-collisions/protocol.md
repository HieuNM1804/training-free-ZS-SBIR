# Can agreement between two genuinely distinct matches verify semantic feedback?

The full GCWE experiment uses offset concentration. Its squared histogram counts a match coinciding with a second draw of *itself*. A dominant isolated patch can therefore look like geometric corroboration. Use the same frozen correspondence probabilities and query-parity groups to test a prediction about distinct correspondences. This is an intervention inside the GCWE verifier.

For independent draws (u,v),(u′,v′) from a normalized patch coupling C, let h be the distribution of v−u. By injectivity of v = u+d on the grid, two matches with the same offset and either common endpoint must be identical. Hence the probability of a matching offset *and two distinct endpoints on each side* is A = Σ h² − Σ C². The probability of distinct endpoints on each side is B = 1−Σ p(u)²−Σ p(v)²+Σ C². The score A/B is the conditional probability of equal displacement among disjoint pairs. In the singular case B=0 there is no corroborating pair and we return zero. Compute the exact probability in each original parity group, average, then subtract the same statistic on the blank. Gallery nomination, rank density, cross-fold word update and all other retrieval scores stay frozen.

Compare the conditional score with original GCWE, the locked centered concentration, ordinary uncentered concentration, A without its denominator, a photo-coordinate permutation, and A/B evaluated on independent marginals. A brute-force enumeration on smaller grids validates both probabilities before scoring. The primary prediction is higher mAP than the existing verifier and both controls that remove aligned physical matching (scramble and independent marginals) on each split. An added gain over raw concentration and A on both splits is needed to support conditioning on distinct matches as the cause. Report precision and class-level uncertainty. Use 1,152 queries per split at seed-42 positions 11,520–12,671. This is disjoint within each split from the discovery and confirmation that led to this test. Develop only on Sketchy.

Spatial correspondence and classical pairwise geometric matching predate this study. The proposed contribution would be separating repeated-token confidence from independent geometric corroboration when transferring semantic evidence across gallery folds.
