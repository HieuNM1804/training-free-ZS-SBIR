# Do geometric observations improve the inferred meaning?

Retrieval can improve merely by amplifying gallery-frequent words. To test the stronger claim about GCWE, evaluate what the query posterior actually predicts. Using the existing split and frozen choices, predict the public word emitted by a uniformly sampled correct-category gallery photo in the held fold. The target distribution is the mean CLIP word distribution over *all* relevant photos there. Use expected log probability, in nats, integrated exactly over words. As a control, evaluate the same prediction on an equally weighted mixture of other categories' photo distributions. Class labels are read only to evaluate already computed predictions. Each query and candidate fold has its own inference, referencing only the opposite photo fold.

Report gains over the native sketch word readout on relevant photos, on unrelated categories, and the difference. A class-independent change of log word scores has exactly zero class-balanced discrimination gain because the category-minus-other target distributions sum to zero. Confirm this invariant numerically. A method can improve mAP without improving this particular prediction; the measures describe different properties. Compare the locked single-event and count-16 models to the independent-distance and shuffled-assignment controls, on the same inputs. A changed ranking alone cannot establish that the sketch now predicts the relevant photos' word observations more accurately.
