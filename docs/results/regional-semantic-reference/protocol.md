# Which position provides additional evidence after global semantic retrieval?

Sharing within-scale positions across candidates improved regional retrieval alone and hurt the same scores once combined with global word retrieval. This was confirmed on new Sketchy queries and full TU. We test an explanation: a region selected for being unusual relative to the entire gallery can be uninformative among candidates already plausible under the query's global semantic evidence.

Let s_i be the original two-view diffused log-word score. Set p_i = exp(s_i)/sum_j exp(s_j), a prior over the indexed gallery for this query. A region r supplies nonnegative word likelihood L_r(i). Bayesian updating gives p(i|q,r)/p_i = L_r(i)/sum_j p_j L_r(j). Replace uniform gallery normalization with this ratio in the position selection step. Retain the candidate's original scale mass and the frozen regional readout. Controls use the original uniform normalization, exactly the same posterior masses randomly reassigned to gallery photos, the semantic posterior only for selecting scale, or the semantic posterior at both levels. Prior mass and raw regional evidence are fixed across the actual and shuffled posterior conditions. No other sketch enters any score.

Reference-game reasoning motivates weighting information by the alternatives a listener might select; pair-conditioned attention has a long history in retrieval. The proposed use of a query-specific alternative distribution acts only within the existing frozen regional module. The primary is the fixed global-plus-regional score using semantic posterior position selection. Pilot on 1,536 queries from seed-42 positions 2,304 through 3,839 of each Sketchy split. These are exploratory queries previously used for a GCWE study. Advance if the primary improves mAP over the original on both splits and beats the shuffled posterior in both. Inspect paired class uncertainty; if the criteria hold, run full Sketchy and all 30 TU classes without retuning and measure the effect within the full GCWE framework. Otherwise report the falsification and keep the original.
