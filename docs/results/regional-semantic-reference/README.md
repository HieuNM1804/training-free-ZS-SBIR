# Normalizing position evidence against plausible alternatives

On 1,536 queries per split, the locked position intervention changed global-plus-regional mAP from 85.365 to 85.316 on Ext-1 and from 77.767 to 77.915 on Ext-2. Precision changed from 84.636 to 84.647 and 75.582 to 75.593. With identical posterior masses reassigned to other photos the controls yielded 85.364 and 77.782 mAP. Only Ext-2 benefited relative to both controls. Changing the reference distribution for both scale and position gave 85.288 and 77.861 mAP. The sign criterion for transfer was not met, so this pilot does not replace the incumbent regional module.
