# Matched object-subspace and orthogonal-complement control

The first Sketchy pilot showed a large effect from noun-space visual projection, while raw cosine harmed the stronger standalone noun-overlap score when fused by rank. Hold input images, bank and evaluator fixed. Compare the visual dot product in the top 250 contrastive noun directions with the orthogonal residual and a random subspace of the same dimension. Verify that the first two sum to the centered global visual dot product. The adapted contrastive basis uses exactly the existing source and target noun prompts. Compare with standard noun PCA to test what the negative covariance contributes.

For fusion with noun-overlap use its log, then min-max normalize each channel over the individual query's gallery. The log is monotone and leaves every standalone semantic ranking intact. Compare mean, product and the prespecified 0.1 Harris penalty with identical normalization, plus matching empirical-rank controls. Separately pair the projected visual score with the centered inferred-text cosine. Test complementary errors for the orthogonal visual remainder as well. The matched factorial has no region, hierarchy, neighbor graph or query expansion. These are distinct adapted readouts and controls, with their own tables.
