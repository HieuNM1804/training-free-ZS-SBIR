# Which image changes rank because this sketch is present?

The previous word update ranks nominees by the difference between their real and mean-color-query spatial scores. A global rank difference does not reveal which image a content-sensitive image displaced in the same choice. We test whether the word readings of the *specific displaced image* carry information. This is a controlled intervention in a frozen computation; “cause” here refers only to changing its input. A uniform canvas removes content and changes the input distribution.

Reuse frozen CLIP ViT-B/32 and the geometry readout from [the preceding experiment](https://github.com/HieuNM1804/training-free-ZS-SBIR/blob/803720d5c830b715326dea26971482164e2154ee/docs/results/geometry-conditioned-word-evidence/freeze.md). Within an opposite gallery fold draw eight photos with replacement from a sketch's 200 visual nominations. Record the winner with the real query and with the uniform query on exactly that same draw. Compute their full joint distribution analytically. The marginal distribution of each winner is the usual maximum order statistic under eight draws. The independent-winner control has exactly the same two marginals but removes the pairing. If this control equals the paired model on retrieval and on predicting held-out orientations, the evidence does not support the proposed contribution. The opposite orientation control treats the blank winner as the real winner.

For a word, the probability of choosing one of two nominees is its smoothed CLIP word response in that photo divided by the sum of both word responses. The smoothing adds one gallery-prior word profile to each donor's word profile. An unchanged winner gives relative likelihood one. Compare averaging one relative likelihood (matched_one), the mean log likelihood at unit weight, and the expected total log likelihood for floor(N/8) slates (matched_log), where N is the actual number of opposite-fold nominees. The latter is a composite score; inter-slate independence is not required for computing its expectation, and its product interpretation is approximate. Arithmetic and log updates, the reverse orientations, independent winners and a simpler ratio of marginal word responses are fixed in advance. The simple question of whether pairing helps uses each version's identically concentrated independent control. The 512 most likely query nouns retain individual identities; all others share an explicit other category, preserving their original relative probabilities. Report retained mass and the rate of winner changes.

The separate mechanistic measurement predicts which nominee wins with the actual sketch on held-out choices from the other half-gallery. It is possible to predict those comparisons better while retrieving the wrong category. Score both outcomes independently and replay the original KD-SBIR metrics on the same two 768-query Sketchy panels. Class labels enter after scoring. A new TU run depends on support from the exploratory comparisons. The underlying geometry draws on [Peyré et al., ICML 2016](https://proceedings.mlr.press/v48/peyre16.html), and the relative choice probabilities use the Luce form used in [Xia et al., ICML 2008](https://icml.cc/Conferences/2008/papers/167.pdf). The exact shared-slate intervention and the matched-marginal falsifier are the part under test. Prior art on verified query expansion is discussed in the preceding branch.
