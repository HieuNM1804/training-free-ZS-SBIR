# Frozen test of gallery-intermediary identification

The pilot on two 768-query Sketchy splits gave 6/61 and 31/124 correct hard-case intermediaries using patch-distance preservation. The nearest source-like photo gave 3 and 17. The effect on aggregate mAP was mixed. This record freezes the TU check before executing any donor or endpoint selection on TU for this experiment. Hardware is Colab Tesla T4 and the encoder is the original OpenAI CLIP ViT-B/32.

For every one of the 2,130 TU sketches and all 27,262 images of the 30 unseen classes, use the original strong base and the top 200 two-view cosine nominees. Keep the upper half by gallery source-description versus target-description evidence, with the first nomination as fallback for an empty pool. This median partition is a diagnostic device to identify the same population. It is not established as a general sampling rule. Compute the spatial correlation of distances between two patch correspondences sampled from the frozen patch affinity. Record the rank of the first relevant donor and the selected donor's correctness before evaluating any change to final retrieval.

Compare with global cosine, equal appearance scores with shuffled spatial indices, order-free patch affinity, direct words and the frozen strong score restricted to the identical pool. Add a content-free canvas filled with the current sketch's mean RGB to test the frozen positional prior. Also report the difference between real and flat-canvas spatial evidence. No subset, strength or combination is selected on TU. Use the donor's public photo-word posterior for the endpoint ranking. Set its own correction to zero and add 1/32 of a standardized endpoint correction to the immutable strong reference. Score with original KD-SBIR. Report oracle word retrieval on a disjoint half gallery as a post-ranking diagnostic only.

Primary localization outcome: selected donor accuracy on strong complete misses for which a relevant upper donor exists. Report all-query accuracy, hard reciprocal rank, fixed full-gallery mAP/P, opposite-half precision, class-macro paired differences and percentile intervals over 10,000 bootstrap resamples of represented classes. The class and depiction filters used to describe errors enter the evaluator after all automatic donor choices. Real geometry should outperform both the spatial shuffle and the content-free control on hard-case donor selection to support a content-specific transfer effect.
