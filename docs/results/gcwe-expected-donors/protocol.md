# Expected donor counts for GCWE

This replaces the split-specific donor update within GCWE. The candidate regional score, cross-domain semantic score, word dictionary, two poses, nearest 200 nominees, geometry signal, eight rank draws and smoothing strength remain fixed.

For each target photo, remove its index from its own nominee list when present. For a pool of n remaining nominees, imagine sampling m distinct donors uniformly and drawing eight times with replacement from those donors. Let K denote the number of distinct donors in the eight draws. Conditional on K=k, these k donors form a uniform k-subset of the n nominees. The probability that the greatest geometric rank is at most j equals the sum over k of Pr(K=k) times C(j,k)/C(n,k). After t draws, a state with k distinct donors transitions to k+1 with probability (m-k)/m. The implementation computes that small recurrence exactly and divides equal-rank probability evenly among tied nominees.

The numerator uses m times the resulting expected word distribution. The denominator uses m times the uniform donor-word mean. Each receives one shared global gallery prior. The prior and downstream diffusion graph still include the target as an indexed gallery image. The target is excluded specifically from its query-dependent feedback. We take the ratio of expected word counts; it differs algebraically from averaging scores produced by independent folds. The rank probabilities are exact for this fixed-size design, which approximates the old random fold's variable number of eligible nominees.

Primary uses m=100 (half the original nomination budget). Controls use all donors, include the target in its own feedback, use the frozen random-fold GCWE, or remove GCWE. All score the same 1,536 queries per split sampled without replacement after the first 768 pilot queries in the seed-42 permutation. This disjoint query sample is exploratory and the two Sketchy splits overlap. Frozen full-gallery KD metrics and paired per-class uncertainty are retained. Exact CDF values are tested against brute-force enumeration of every donor subset and every sequence of draws for n=5, m=3, draws=4.

Evidence for eliminating random-fold variation requires better equal-split mean mAP than the original update and a gain on each split over turning feedback off. Evidence specifically for target exclusion additionally requires an advantage over the inclusive control. A deterministic scorer alone does not establish a better semantic estimate. Classical spatial verification and the project's existing GCWE supply the mechanism; the proposed change is a target-specific, analytically marginalized word update. [Chum et al., ICCV 2007](https://www.robots.ox.ac.uk/~vgg/publications/2007/Chum07b/)
