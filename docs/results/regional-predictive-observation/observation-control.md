# Can this instrument recognize a predictable visual part?

In the paired source test, the sketch readout comes from a crop encoded independently, while the candidate photo describes each region using contextualized tokens from a full image. Check whether the negative result follows from these incompatible observations. Reuse precisely the same photo pairs and the same native 64 public word heads. Cross the input (actual sketch or its reference photo used as a positive control) with the candidate observation (whole-image patch readout or the same nine crops independently passed through the frozen image encoder). For the reference-photo query use the same source text prompts as for the sketch, maintaining the source/target template difference. A photo used as its own reference is an intentionally easy positive control with repeated pixels, outside the official SBIR benchmark.

For each cell evaluate the existing conditional forecast, uniform placement, cyclic source-to-destination reassignment, and a fixed absolute-position prediction that reads the known destination crop directly from the candidate. This last intervention is an alignment positive control for identical photos and an explicit assumption to test on actual sketches. A positive result confined to the self-photo control shows the instrument can carry location-specific semantic content but does not demonstrate cross-domain transfer. A gain on sketches should improve the true-minus-foil predictive contrast as well as forecast quality. Report whole-sample and same-class fixed-pair assignment accuracy with paired 95% intervals. No tuning on these measurements.
