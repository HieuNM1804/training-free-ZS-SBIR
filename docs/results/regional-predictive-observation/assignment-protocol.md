# Test source information after conditioning out a photo pair's fixed preference

The native decision can favor the same candidate whichever drawing is supplied. It can be highly reproducible across redraws yet convey no information about which of the two photos generated the drawing. Use both sets of independent drawings from each preselected pair after scoring. A two-drawing, two-photo assignment cancels any fixed lexical or regional advantage of one photo over the other.

For reference photos i,j and their independently encoded drawings x,y respectively, define m(x)=s(x,i)−s(x,j). The correct assignment wins iff m(x)>m(y). Define pair accuracy by averaging this event (ties receive half credit) across all x,y of that pair. This equals the within-pair AUC for source identification, retains exactly the same photo pair, and needs no training. Average over pairs equally and bootstrap entire pairs. Query and candidate soft scores were already computed independently of other sketches. The assignment is evaluated post hoc only. It supplies no sketch-to-sketch signal at retrieval.

For same-class source pairs compare the native global word channel, the regional predictive log score, the uniform-anchor forecast, spatially shifted anchors, and the regional incremental log score (conditional minus marginal). The principal diagnostic is whether the regional increment correctly orders sources when the *native global score orders them incorrectly*. Exclude ties in the native score for this conditional subset, include ties as 0.5 for the regional test. In this group require performance above 0.5 and higher than the shift-minus-marginal sham on both splits before claiming conditional semantic information. Difficult cases selected via global errors form a diagnostic stratum, not a deployment gate. Report also all ordered pairs, class-level heterogeneity and wrong-direction controls. Across-category reference pairs provide a positive control. Correct an ambiguity in the previous formulation: preserving mean rank does not imply effective semantic identification if the photo pair is decided by the popularity of one candidate.
