# Does a candidate predict unseen semantic content in a sketch?

Use the same two-image reference trials as the global identification test. A correct candidate should forecast the semantic content of a separately encoded part of the query before seeing it. This is a test of conditional information. A high local match alone need not make a good forecast.

Use four corners from the existing nine native 3×3-token crops on the 7×7 sketch grid. For each anchor A, forecast the horizontally opposite and vertically opposite corner B separately. A and B share zero input pixels. The sketch is cropped before CLIP encoding. All nine photo regions are summarized by the mean of their contextualized CLIP patch-token posteriors on the gallery's frozen 64 public heads. The photo decoder sees the full candidate. Its patch responses and the sketch crops have different observation models.

Given candidate d, distribute posterior mass across photo anchor locations j proportional to the overlap of the observed sketch word distribution with photo words at j. Restrict j to locations for which the displacement from A to B leads to a valid photo region. Predict the entire 64-word distribution at B by marginalizing the photo distributions at those destinations. Only afterward, measure the log probability under the target sketch crop's frozen word readout (expected log score, nats). The forecast can be checked independently of its use in ranking. No actual second drawing enters the predictor.

Compare against a model using the same candidate and the same allowed destination regions under a uniform anchor prior, and both non-identity cyclic reassignments of source-to-destination correspondence (average the scores). These preserve the set of candidate descriptions and the query measurement. Report the proper-score difference for the true candidate, the same change for its foil, and their paired difference. The first contrast tests predictability. The second tests whether any new information distinguishes the target. Evaluate same-category original photos and cross-category foils separately, including pairs on which the global channel abstains. Gains in forecast quality for both candidates equally would fail the discriminative claim. Rank decisions are diagnostic and distinct from the official KD category metrics. Average over four corner anchors and both held-out directions, aggregate by original photo pair, and bootstrap pairs within each split. Each split must improve both true-candidate forecast and its contrast with the foil over the spatial shuffle before this can support an algorithmic claim.

SCAN conditions local alignment on a candidate. Predicting genuinely withheld evidence has precedent in masked image modeling. The construction tests a conditional distribution for a new sketch measurement from an observed part and a target photo.
