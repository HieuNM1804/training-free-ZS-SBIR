To interpret it, replay the *same* new source pairs, measure the native complete-vocabulary two-view semantic margin, and ask how often local readings resolve source assignments that this global score gets wrong. This is a diagnostic selected after the layout experiment, on the same pairs. It cannot serve as fresh confirmation.

These interventions permute encoded content, leaving every local descriptor identical. They test dependence on the original coordinate frame, not invariance of CLIP under image rotation.
