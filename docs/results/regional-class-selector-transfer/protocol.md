# Can another photograph from the same category supply the regional selector?

The adjacent-photo control preserved most of the regional advantage on contested ranks. Test whether this reflects a selection pattern that transfers between distinct exemplars of a category. This is a gallery-label intervention restricted to the two development splits. It is a mechanism assay, not a deployable ranker. There is no fitting. Query labels are used only for the final assessment. All word vectors, photo values, region weights, and rankings used to form the trials are frozen before reading gallery labels.

Use the previous 768 independent sketches on each split and the same adjacent pairs among the top 200 photos of the native diffused semantic rank. For each endpoint c independently, sort the full gallery by the score of the whole sketch in the regional dictionary. Examine symmetric offsets 1 through 64 on either side of c. An eligible offset has one selector photo in c's gallery category and one outside it. Exclude the two endpoints of the pair from the donor pool. Take the nearest eligible offset with the same-category photo above c and the nearest with it below c. Require both orientations and valid comparisons for both endpoints. This matches donor rank distance exactly within each comparison and balances the direction of rank. Within-category donor and across-category donor each contribute two sets of normalized window weights. Their arithmetic average is a mixture of selectors. Score the original candidate's frozen window values under each mixture. Report coverage and effects of exact ties in the whole-view selector ranking. Conditional on these matches, the two donor groups may still differ in appearance, abundance and word content.

First check whether same-category donors assign more probability to a candidate's own high-evidence windows. Then test the stronger claim: on a mixed-relevance pair, does this help the correct photo more than the other one? Report matched log-score changes for both endpoints, their difference, and the change in accuracy balanced over the two directions of the original semantic decision within each sketch. Also report the score using the candidate's own selector on precisely the same support. Require positive true-minus-foil change and positive balanced accuracy change on both splits with class-bootstrap intervals above zero to support an incremental contribution to category retrieval. A stronger score for every candidate cannot establish improved discrimination. All comparisons are post-selection on the Sketchy pilot. No official gallery retrieval score is defined for this oracle subsample.
