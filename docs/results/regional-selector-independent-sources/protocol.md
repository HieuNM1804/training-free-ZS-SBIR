# Confirmatory cohort for transfer of regional selectors across photo exemplars

Repeat the frozen symmetric-donor experiment without any change to window weights, ranking, eligibility, rank radius or endpoint. On each Sketchy split take one drawing at random (seed 42) from every reference photo whose drawings never appeared in the discovery cohort of either split. Validate each source key against the official gallery. The two splits may share classes and photos with each other. Report each split and the number of supported queries. Class-bootstrap intervals apply to a class-equal estimand, while the main means weight supported queries equally. The extent of overlap with unrelated historical retrieval studies has not been audited. Keep the decision criterion in the original protocol. These labeled donor comparisons test transfer of the selector and do not produce an official retrieval score. [Intervention and endpoints](../regional-class-selector-transfer/protocol.md)
