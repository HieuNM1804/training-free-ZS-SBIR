# Can a local observation alter a scene interpretation in a way that transfers to another drawing?

The previous scene-word pilot chose its prior from an isolated corner. Its 64 words covered just 2.4–2.6% of the third crop's probability mass. Its local forecast and category retrieval could fail because of a poor context or because a scene word cannot mediate the observation. This experiment replaces the observation model in GCWE. It preserves probability on the entire vocabulary and examines both a new drawing and a real reference photo.

For each of the four 3×3 corner windows B of the native 7×7 grid, encode the full image with B replaced by the CLIP input mean, also using its horizontal reflection. These embeddings specify the global scene prior a(W) and nominate 100 gallery photos in the opposite fold. The context around B remains intact. Use each of the two horizontally or vertically opposite corners A to predict B with the previously fixed regional operator, and average their forecasts within each donor photo. Read B only after the forecast is formed. A→B geometry, crop orientation and donor ranks are fixed without reading B. Repeat with both cyclic shifts in the photo placement and average their forecast probabilities.

Let D(d|w) be each donor photo's native public word probability normalized across donors for w. Let H(d,u) forecast B's public regional readout from d and A. Compute e(u)=Σ_d,w a(w)D(d|w)H(d,u). The region B gives soft evidence y(u). Update the scene by a′(w)=a(w)Σ_d D(d|w)Σ_u H(d,u)y(u)/e(u). The update is the marginal of a joint probabilistic model after Jeffrey conditioning. It has unit mass. It returns exactly a when y=e. It can be computed using two matrix-vector contractions even with 20,931 possible words. Average predictions across held-out corners. Computational checks include a small exact expansion of the joint, conservation of mass and the neutral observation identity.

Controls keep the same full scene support and nominations: masked-context prior, spatially shifted observations, and a deterministic within-neighbor-rank-group reassignment of word descriptions among the same donors. Include the direct frozen CLIP reading after revealing B (the original whole sketch) and a restricted top-64 masked-context prior/posterior, reporting retained mass on a separately drawn sketch. The masked prior isolates added information, the shams test location and the attachment of semantic words to actual photo donors. For the restricted variant rank candidates by its raw overlap, without renormalizing gallery words onto the restricted support.

Select 768 queries per Sketchy split at seed-42 permutation positions starting at 5,376 after excluding IDs used in the preceding 768-query pilot in either split and any source with only one drawing. Use the same selection for all arms. Score the full gallery with KD-SBIR. Separately compute the expected log probability of (a) the global frozen source-word reading of the other drawings from the same source (equal-weighted, excluding the current drawing), (b) the public target-word reading of the true reference photo, (c) readings of drawings from another reference in the same class. Reference IDs, class labels and other drawings enter **only after all query predictions are frozen**. In these post-hoc forecast tests use the scoring fold of the true photo, so that photo could never supply the word evidence for its own forecast. For the within-class foil rotate sorted reference-photo IDs by one; this tests source specificity, not a random draw from all incorrect instances.

The primary test requires better held-out redraw log score than the masked prior, reassigned donors and shifted layouts on both splits; photo prediction, correct-versus-same-class redraw margin, paired class uncertainty and retrieval are separate endpoints. Exceeding the native full-sketch result would be stronger evidence for retrieval. Compare masked-crop selection with the earlier isolated-crop numbers as descriptive only. A proper scoring gain that also appears equally for another same-class source would indicate broad category information. TU remains excluded from development.
