# Do conditional region forecasts resolve natural category-retrieval errors?

The preceding redraw trials evaluate which photograph supplied a drawing. Category ZS-SBIR instead treats every gallery photo from the correct class as relevant. Test the same fixed semantic readouts on the official class boundary. Encode the four independent corners in the prior split-specific gallery vocabulary. Freeze the query-only geometric-mean prior from the other three crops, the raw registered photo forecast, the candidate-specific reporting-channel forecast and its fixed quarter-turn. The sole change to the latter is a spatial reindexing of the candidate's readouts. For calibration controls include the unregistered photo mean over its four crop distributions. Higher expected log probability of each held-out sketch corner is better. The contextual model's score ranks candidates equivalently to its information above the query-only context because that term is identical for every photo.

Use 768 queries per original split at seed-42 permutation positions 9,216 onward, excluding query IDs from the recent grounded-word and three GCWE inference pilots in either split. Every retrieval score is computed for the complete official gallery before reading relevance. Report the official KD mAP and precision for each predictive model (direct and after the native RGB graph), the native global semantic channel and the original candidate-conditioned regional term. For the graph input convert log probabilities back to probabilities with a query-wise offset. No mixing coefficient is fitted and these scores are not added to the three-component framework.

To measure incremental discrimination conditional on global rank, form disjoint adjacent pairs (1,2),(3,4),…,(199,200) of the frozen diffused whole-sketch semantic ordering. Then inspect pairs containing one correct-category photo and one incorrect-category photo. Report average ordering accuracy within each query and separately when the global score was correct or wrong. Also report accuracy balanced equally across these two directions within queries with both kinds of pair. A claim about complementary category information requires the registered visibility model to exceed 50% balanced accuracy and its rotated control on both splits, with class-bootstrap bounds. Record raw rescued and damaged decisions; publications should disclose if most queries have no contested pair in the top 200. A positive within-source assignment result cannot substitute for this test.
