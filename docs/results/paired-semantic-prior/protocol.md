# A gallery prior from paired lexical observations

The preceding S-only experiments show a consistent mAP gain from fitting the existing gallery concept prior and a loss when enforcing two distinct lexical matches for every candidate. Test whether agreement between existing domain-specific readers can improve the reference measure rather than suppressing an individual query's single strong match.

For each unlabelled photo (i), the two fixed word readers return target-domain posterior (p_i) and source-domain posterior (a_i). Use (L_{iw}=sqrt{p_{iw}a_{iw}}) as the contribution of a latent shared concept to a composite likelihood. The geometric mean treats both observations equally in log space and gives the original response if the readers are identical. Fit only the gallery histogram (pi) by maximizing (sum_ilog(sum_wpi_w L_{iw})) on the simplex with existing mixture updates. This is a numerical estimate of a reference distribution, with all CLIP weights and prompts fixed. It imposes no exact conditional independence on the two CLIP measurements. Their probabilities are a scoring proxy for word likelihoods.

At retrieval, return to the usual target posterior and correct only its prior. The S score is (q^	op (piodot p_i)/(pi^	op p_i)). Retain the same full 20,931-term vocabulary, the same sketch readings, and every gallery image. Neither regions, geometry, gallery diffusion, other queries, extra views, nor labels enter scoring.

Controls fit (pi) with only (p_i), only (a_i), their arithmetic mean, or the same geometric mean after a deterministic derangement of the source reader over the photos. The derangement preserves each reader's marginal evidence across the gallery. All five priors enter the same target-posterior ranker. Replay direct S and the existing photo-only prior, evaluate every unseen query with KD-SBIR, and record paired differences for the new prior relative to each control. Freeze this recipe before evaluating any new variant. Keep the same recipe and original metrics on Sketchy Ext-1, Ext-2, and TU-Berlin with all 30 classes. Run on Colab T4, OpenAI CLIP ViT-B/32 and seed 42.

The probabilistic motivation is shared latent membership across measurements as in [Anandkumar et al., COLT 2012](https://proceedings.mlr.press/v23/anandkumar12.html). We use neither their identifiability assumptions nor their tensor estimator. The vocabulary bridge is inherited from [FreeDom, WACV 2025](https://openaccess.thecvf.com/content/WACV2025/html/Efthymiadis_Composed_Image_Retrieval_for_Training-Free_Domain_Conversion_WACV_2025_paper.html). The tested contribution is a paired reference distribution with the deployed posterior and ranker held fixed.
