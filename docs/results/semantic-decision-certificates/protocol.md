# Which word distinctions can falsify a candidate after arbitrary regional information loss?

The shared-channel pilot measured how well a four-state transformation estimated from one subset of words predicts another. Better absolute prediction on the query sometimes transferred to the distractor too. This full-gallery test asks for a necessary condition for an image to explain a sketch even if the transformation is unknown. It needs no estimated layout or per-candidate optimizer.

Let Pᵤ and Qᵤ denote the candidate and query distributions over four independently read regions for word u. If Qᵤ = Pᵤ K for every word under a common stochastic map K, the accuracy of distinguishing any two equally likely words from the observed region cannot increase. The optimal binary accuracy is (1 + TV(Pᵤ,Pᵥ))/2. Thus an observed improvement is a certificate against that candidate. More generally, for any map with maxᵤ TV(Qᵤ,Pᵤ K) ≤ ε, the triangle and contraction inequalities imply D(Qᵤ,Qᵥ) − D(Pᵤ,Pᵥ) ≤ 2ε. Compute L = ½ maxᵤᵥ [D(Qᵤ,Qᵥ) − D(Pᵤ,Pᵥ)]₊ for every query/photo pair, with all 2,016 distinct pairs of the frozen 64 gallery words. Small or zero L only passes these binary necessary conditions. A joint channel need not exist. L is unchanged by any global relabeling of the four regions in either image.

Compare a candidate ruled out by the nominal words versus the same capacity profile under a swap of neighboring gallery-frequency word identities. Sort the distance vector of each depiction and compare corresponding quantiles to obtain L_free, the minimal bound under an arbitrary permutation of the **word pairs**. Sorting solves the bottleneck assignment by removing inverted matches; the relaxation also permits permutations that no consistent relabeling of the words can realize. Test L−L_free as the part caused by the identity of the word pairs, and the reverse direction to check whether the arrow of information loss matters.

Use the same 768 single sketches per split and complete gallery as the earlier category-boundary measurement. Run the original KD evaluator. Report the native diffused whole-image semantic rank, the order induced by each bound, and a logical filter that first keeps photos with no witnessed contradiction and otherwise preserves the native order within both groups. Use native semantic rank for exact ties in each certificate ordering. Record the fraction passing at a tolerance of 2e−6 in TV-bound units (for floating-point summation), both for all photos and in the native top 200. Also report certified lower bounds and prevalence of violations separately for relevant and irrelevant candidates in mixed adjacent native pairs. Primary retrieval tests are a positive mAP effect of the logical filter over native on both splits, and superiority of the named bound over both the word-identity swap and the free-pair control on both splits. Bootstrap classes and report both official metrics. The use of the 64 public words measures relative spatial information within a restricted lexicon. The necessary condition alone does not assert semantic relevance.
