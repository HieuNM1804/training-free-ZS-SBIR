# Rank-preserving crop calibration

GPU Colab L4; OpenAI CLIP ViT-B/32 frozen; full unseen Sketchy galleries and public Open Images words. Each query is processed independently. The pre-existing regional and hierarchical retrieval components use the published internal freeze in research/view-disputed-words. The run command is `python -m tf_sbir.rank_preserving_crop`. The metric calculation was checked using the KD-SBIR original rank replay on one sketch per batch for each row. Results are exploratory. The archived JSON includes paired differences and class-bootstrap intervals.

The experiment asks whether crop-driven changes to global concept identities are necessary at the input to the frozen gallery propagation step. For each sketch, sort its public word indices by the average posterior across two whole-image poses. Project crop probabilities onto this order by least-squares isotonic regression. Then combine the projected distribution with the two whole images. Compare with the unprojected crop, a rearrangement preserving the crop probability spectrum but discarding word identity, and a query-specific entropy-matched temperature. Order-preserving calibration has a long history in supervised probabilistic prediction. The adaptation here projects predictions from unlabeled views of one image. [Zadrozny and Elkan, KDD 2002](https://www.cs.columbia.edu/~djhsu/ML/handouts/zadrozny2002kdd.pdf)

The projection exceeds raw crop pooling on both splits, but differs by less than 0.01 mAP points from rearranging the crop values onto the same global rank order on either split. Its class-bootstrap intervals against rearrangement include zero on both splits. Entropy matching scores higher on Ext-2. The experiment does not support using isotonic fitting as the main scientific contribution. TU was not used for selection or evaluated on this branch.
