# Predict semantic changes under an intervention defined only by part geometry

GCWE's strongest evidence to date concerns how geometry changes donor selection. Here the task is to infer a word-level consequence *before* any changed sketch is encoded. Divide the native 7×7 ViT grid into a fixed central cross and four 3×3 corner blocks. Exchange the pixel patches of two blocks, preserving every patch exactly once and its within-block order. A word response to this intervention can reflect the composition of parts; both word frequencies across the original image and the collection of patch contents are held fixed by design. The rearrangement is an experimental manipulation of CLIP and need not resemble a natural drawing.

Infer an uncertain correspondence g of the four blocks from the untouched sketch and candidate only. From native contextual patch embeddings, compute the frozen CLIP soft assignment of each of the 36 corner patches to the photo's 36 patches, pool probabilities to four blocks, and average the forward/reverse log likelihood of each bijection. Normalize the four-region product over all eight square isometries. A sketch operation exchanging a,b maps to the operation exchanging g(a),g(b) on the candidate. This is conjugation of the intervention by the inferred correspondence. Map uncertainty induces genuine alternatives for the semantic consequences of an action, even for a fixed photograph. Compare uniform square maps, fixed native coordinates, and all 24 appearance-supported bijections to separate structure from patch appearance. The original GCWE donor ranking and similarity weights are not changed. This is an experiment within the GCWE geometric-to-semantic inference question.

Pair every exchange with its disjoint complementary exchange of equal distance. Draw one public word from the frozen semantic readout of each **intervened sketch**, then ask which word belongs to which operation. Candidate predictions use only untouched sketch geometry and the candidate's two transported photo interventions. For fixed g, classify assignment with the 2×2 conditional log-odds ratio; a word-specific prior preference and an operation-wide additive logit offset cancel. Average the assignment probabilities over the prior from the untouched images, conditional on the unordered pair of words presented to the predictor. This is a specified conditional model; it does not infer human labeling probabilities. Sampling the test outcomes occurs after the candidates' forecasts are specified. Use 2,048 draws per operation pair with a seed derived from sketch ID; include repeated words as exact ties. Score the expected Brier loss of deciding the correct assignment and accuracy of selecting the true photo over a hard rival. Also report expected assignment accuracy and direction probability. Shared seeds pair arms and foils. Uniform over the square group must return exactly 1/2: each pair of opposite equal-length operations has a group element interchanging it with its complement. Validate this against the computed expectation and force the analytical tie. The fixed-coordinate readout and unrestricted nonuniform bijection are nondegenerate controls.

The hard within-class and across-class pairs and seed-42 query choices are frozen from the regional reveal study. Measure how a known horizontal flip of only the sketch changes estimated correspondence and forecasts. Check the raw patch transport against explicit pixel exchange and the identity readout against native CLIP. Prespecified primary tests on original sketches are improved true-source Brier risk versus the fair and coordinate-registered forecasts, and improved true-minus-foil separation versus registered and unrestricted correspondence on both splits, with uncertainty clustered by photo pair. Inspect the same tests for flipped sketches separately. The paired-source assay must produce a reproducible semantic advantage before evaluating full gallery category mAP or TU.

Functional maps provide the principle that correspondence transports operators between domains. DisAmb already uses a learned shape-jigsaw criterion in SBIR; this experiment tests zero-training inference for the *consequence* of a counterfactual rearrangement rather than learning to classify shuffled parts.
