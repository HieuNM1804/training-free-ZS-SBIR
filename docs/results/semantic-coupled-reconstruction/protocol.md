# Retrieve a photograph by predicting its CLIP features from an incomplete depiction

A sketch can support several related public words. Two individually plausible names may encode almost the same direction in source CLIP. Summing their probabilities treats both as independent contributions to a predicted photograph. Test the hypothesis that estimating coordinates which jointly reconstruct the observed sketch, then decoding those coordinates in actual photo-feature space, improves retrieval. This is a standalone inference rule in Cross-Domain Semantic Retrieval. Inputs are one sketch, the unlabeled gallery and the fixed Open Images vocabulary. It uses frozen OpenAI CLIP ViT-B/32, seed 42, no gradient, and one native image view.

Select the K source-prompt text vectors with largest sketch cosine. Let S have these vectors as rows. Find the affine coefficients minimizing ‖q−Sᵀa‖²+η‖a−1/K‖² subject to sum(a)=1. The closed-form equality-constrained ridge solution can assign negative coefficients. The query thus expresses a relation to a set of words, including the part that correlated names overpredict. Use fixed η equal to 0.1 times the mean squared distance of the selected atoms from their centroid. Fit no model weights. Test K=16, 32, 64, with K=32 primary and the other two a prespecified exploratory sensitivity check.

For every word obtain its visual mean in an unlabeled reference half of the photo gallery, using frozen CLIP photo-to-word probabilities over *all* 20,931 words. Compose these target means with exactly the source coordinates to predict a target photo feature. Under a shared Gaussian covariance for photo features, retrieve by the predicted-feature versus gallery-background log likelihood ratio, including its quadratic normalization. Regularize the covariance by 0.02 times its mean eigenvalue. A candidate and the gallery that supplied its decoder are always in opposite halves. The same score and parameters apply to every candidate and query. The Gaussian is an explicit modeling assumption on unit-normalized CLIP coordinates. Reference photos supply unlabeled statistics only.

Controls use frozen visual cosine, direct full-vocabulary agreement, the same K words weighted by native CLIP softmax, an isotropic target covariance, and transport into target text space with the same coordinates. The primary comparison is against both the full-vocabulary semantic baseline and soft weights with the identical visual decoder. A gain over visual cosine alone is insufficient. Use a seed-42 permutation of 1,536 queries per Sketchy split and score the original complete gallery with the KD evaluator. Report both metrics and class-bootstrap contrasts. If an affine variant improves both development splits, test the chosen support size on every remaining Sketchy query, then evaluate the fixed choice on all 30 TU-Berlin classes if its advantage replicates. The diagnostic input audit plays no role in fitting, scoring or parameter selection.

Shared coefficients across two representations have a concrete precedent in coupled patch dictionaries for super-resolution. Local affine reconstruction is also established in locally linear embedding. The proposal here uses source prompt coordinates to decode a conditional *photo distribution*, with retrieval testing the implied change of domain. These precedents limit any claim of novelty to the retrieval formulation and evidence about it.
