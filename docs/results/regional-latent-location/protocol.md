# Is a candidate choosing a physical location or just the scale of a crop?

In the original reader, decompose the attention over the 13 windows into the probability of scale and the conditional probability of a position at that scale. Share either factor across candidates using the marginal attention within the same query, and leave the other candidate-specific. Compare with the original and with sharing both factors. These controls reuse the exact same visual and semantic evidence.

The proposed intervention instead takes the latent variable to be one of the 49 original patch centers. For a chosen center, give equal mass to the two scales and distribute each scale's mass uniformly among its windows containing that center. Multiply this fixed 49-by-13 incidence matrix by the regional likelihoods. Run the original gallery-normalized, candidate-conditioned attention on the resulting position likelihoods. There is no new encoder, image view, learned parameter or center threshold.

Control one keeps the original windows, changing their prior to the exact marginal induced by uniform latent positions. Control two reflects the incidence map of the large windows only. This leaves each scale's geometry and the mean evidence of every candidate unchanged while altering where the scales coincide. Query and photo use the existing frozen word readout. Earlier nested-scale work in this repo estimated word-pair dependence in both images; this experiment changes how a single query's overlapping windows measure a common latent position. Pair-specific attention already has precedent in retrieval. [SCAN, ECCV 2018](https://openaccess.thecvf.com/content_ECCV_2018/html/Kuang-Huei_Lee_Stacked_Cross_Attention_for_Image-Text_Matching_ECCV_2018_paper.html)

Use 1,536 fresh queries per split, seed-42 permutation positions 5,376 through 6,911. The primary standalone regional score must improve equal-split mean mAP over the original and beat the marginal-prior and displaced-position controls on both splits before a full transfer test. Report the same intervention with frozen global word scores as well, and provide both KD metrics and class-bootstrap intervals.
