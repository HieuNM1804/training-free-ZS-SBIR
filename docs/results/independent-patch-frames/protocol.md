# Is some apparent agreement due to using the same learned coordinate labels?

Spatial verification against a permuted distance grid improves mAP on full Ext-2 and TU in the preceding study. That intervention established that positions matter. It cannot distinguish the physical layout of the input from a ViT token's learned preference for an absolute location. Yang et al. traced grid artifacts in ViT features to input positional embeddings and used optimization to denoise them. Their finding motivates a frozen, pairwise intervention. [Yang et al., ECCV 2024](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/11504_ECCV_2024_paper.php).

Retain every RGB pixel, convolutional patch, physical coordinate and learned parameter. Supply four already existing position tables to the frozen transformer by reflecting the native table horizontally, vertically or in both axes, or leaving it in its native orientation. Each table is an isometry of the same physical grid. Keep the class token and its position. Encode every image under all four assignments. The independent-frame affinity is the average over all 16 query/gallery frame pairings. It equals the dot product of the unnormalized mean descriptors from each side. The same-frame control averages the four diagonal pairings, and the mismatched-frame control averages the 12 off-diagonal pairings. The difference between same-frame and independent-frame affinities is the cross-image covariance of descriptor change under frame relabeling. Test that covariance alone, and match the independent matrix's dispersion to the same-frame matrix to check a temperature effect. Compute native, same-frame and independent variants both before and after subtracting the uniform-query geometry score. Grid distances in this last measurement are always the true geometric distances. The averaging precedes the nonlinear patch softmax.

The hypothesis predicts that exposing the same labels creates spurious patch matches at identical grid sites even on content-free input. Removing correlated frame response should reduce the diagonal probability and select more relevant nominees, then improve retrieval versus both native and same-frame controls. A reduction in the blank diagonal without a retrieval gain would show that deleting that particular artifact is insufficient, or that canonical layouts carry useful semantic information. Reflection averaging can retain position information shared by all four frames, including radial layout. This is a targeted test of correlated orientation-sensitive signals, not a removal of every position effect.

Use the same 768-query Sketchy samples, 200 visual nominees, identical posterior update with eight draws, full galleries and the original KD evaluator. The strong scores and original lexical geometry are replayed. All image encodes run on Colab with ViT-B/32 without updates or gradients. Cross-domain correspondence already uses geometric verification, including [Lee et al., ACM Multimedia 2014](https://doi.org/10.1145/2647868.2655032). The particular question here concerns the coordinate reference shared by the **two encoders' outputs**.
