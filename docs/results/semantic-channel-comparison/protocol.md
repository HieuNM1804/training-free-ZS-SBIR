# Can an image simulate the distinctions between words that a sketch still preserves?

Within Cross-Domain Semantic Retrieval, describe each depiction as a statistical experiment. Its inputs are the same public words, its outputs four spatial regions. A row is the CLIP probability of a region conditional on one word: normalize that word's frozen crop logits across regions for each rendering, then average the two renderings. A word-specific logit offset cancels exactly. A richer photo could have different coordinates, merged parts, or finer distinctions than the sketch. If the sketch were obtained from the candidate by losing regional information, then **one** row-stochastic matrix K would take the photo's distributions over regions to the sketch's, simultaneously for different words. An independent transformation for every word could fit any sketch and would give no evidence about the candidate.

Use classical Blackwell comparison of experiments and finite Le Cam deficiency. On 32 calibration words solve exactly the linear program minimizing the maximum total variation distance from the observed sketch rows to P K. Each total variation constraint is the maximum over the 14 nontrivial subsets of four regions. Select no hyperparameter from scores. The calibrated matrix must predict the other 32 words. Then exchange the two folds and average. This is per-pair inference by linear programming on four observations per word. It uses a frozen encoder, no gradients and no parameter shared across queries. Prior art provides the order and deficiency. The proposed application is a falsifiable, one-way semantic observation model for retrieval, with evidence assessed on words excluded from its inference. The order itself is established. [Blackwell comparison and channel approximation, ISIT 2011](https://maxim.ece.illinois.edu/pubs/raginsky_ISIT11.pdf) · [Coarse-graining and the Blackwell order](https://www.mdpi.com/1099-4300/19/10/527)

Use the previously frozen within-class and cross-class source pairs, randomly choose one sketch per source and a separate redraw of the same source using seed 42. Read each sketch independently. Fit the channel with the first sketch only. The second sketch is an additional outcome. No redraw is an input to retrieval. Report the negative mean held-word total variation, the true-minus-foil margin and the fraction of source decisions correctly ordered with ties worth half. Compare to fixed registration, the best fitting permutation of four corners, a constant prediction independent of photo content, and a held-word identity swap. For the last control, keep the calibration and all test-word spatial distributions, swap neighboring gallery-rank word identities within the withheld fold, and reuse precisely the same K. Include the reverse channel (which depiction can simulate the other?) as a diagnostic. Use paired bootstrap by source-photo pair. Test solver feasibility and objective values against an exactly simulated stochastic degradation, a non-simulable decision problem, and a coordinate permutation.

The proposed mechanism needs both (i) a gain for the true source versus the query-only constant and (ii) a gain in its true-minus-foil margin versus fixed registration and the held-word identity control on both splits. Inspect same-class and different-class cases separately; both must pass before proposing a retrieval replacement. Report whether generalization survives a second drawing. These trials concern original source identity, not full-gallery category mAP. They are exploratory and share photo sources with earlier diagnoses. A highly informative photograph can simulate many sketches; passing the feasibility test alone cannot establish relevance. If estimation on the observed words is ill-conditioned or the empirical minimax solution is nonunique, the held-word forecasts pertain to the specified solver's deterministic optimum.
