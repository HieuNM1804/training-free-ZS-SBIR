# A semantic hypothesis that makes a prediction before a sketch region is revealed

GCWE currently asks which donor has strong geometry and transfers that donor's words. Here a public scene word is an explicit latent variable W. It must explain how observing one region changes the predicted meaning of a different, unseen region. Forecasting offers a falsifiable semantic task independent of retrieval.

Use three nonoverlapping, separately encoded sketch corners A,B,C. For each of four anchor corners A, B and C are its horizontal and vertical opposites; swap their roles for a second trial. Restrict the scene-word support to the 64 largest native public word responses to A, with a normalized prior a(w). In the opposite gallery fold nominate the 100 photos most similar to the observed crop A, before reading either B or C. Let D_w(d) be proportional to the frozen gallery photo-word posterior at w over those nominees. A scene hypothesis thus supplies a conditional distribution over possible donor photos. The local observation alphabet comprises the 64 gallery heads already defined by the regional baseline. Scene words and observation words are different variables.

For each donor compute the forecast H_B(d,u) of a word u in B by marginalizing the location of A and translating to B in that donor. Define H_C analogously, from A only. Under W, select two potentially different donor photos independently for the observations. Then M_B(w,u)=Σ_d D_w(d) H_B(d,u), and similarly for C. The probability model defines p(w|A,u)∝a(w)M_B(w,u). For the observed normalized soft word readout y_B, apply Jeffrey conditioning a′(w)=Σ_u y_B(u)p(w|A,u). Forecast C by a′ᵀM_C. For the control that keeps the same donor for both observations, use the induced prior t(d)=Σ_w a(w)D_w(d) and condition t on y_B in the same manner. Both models have exactly the same one-region marginal predictions for B and C. Their dependence structures differ. A third control draws a new scene word for C, giving the unconditional forecast aᵀM_C. Also repeat semantic inference with cyclically shifted spatial correspondences. Validate normalization, equality of one-region marginals, and return to the prior when y_B equals the predicted observations.

Primary test on 768 queries per Sketchy split from seed-42 positions 4,608–5,375: compare the expected held-out log probability of C (nats) for shared W against independent scene words, the same literal donor, and a shifted spatial map. Inspect improved and worsened classes. A useful semantic mediator should beat these controls on both splits. The forecasts never receive C, a second sketch or benchmark labels. Separately test whether a′ predicts the scene-word readout of C better than a or a direct two-crop CLIP posterior, with C's mass on the proposal disclosed. The 64-word variables are CLIP readings of content, not human annotations.

For full-gallery category retrieval use a′ as the scene-word query against unchanged gallery word banks (cross-fit over photo folds) and the existing gallery graph. Average candidates' scores over all eight ordered corner trials before applying the graph. Compare against the same A-only proposal and directly pooling A,B on that support; include the intact native semantic module with the full dictionary as a scale reference. Use the original KD evaluator and both metrics, without regional or GCWE score fusion. This is a separate mechanistic pilot; TU stays locked.

SCOT motivates geometric correspondence, the context-to-target prediction question comes from conditional neural processes, and the soft posterior update is an application of Jeffrey conditioning. The word-mediated, spatially conditioned prediction of an unobserved sketch reading with matched photo- and word-persistence controls is the contribution under test.
