# Which transfer fails for a question built from two rival photos?

Use the *exact* questions, selected class-boundary cases and controls of the pilot. Three distinct real images matter: the nominated relevant candidate, its different source photo from which the human produced the query, and the rival. First fix the wording to the sketch templates throughout. Change only the observation used to answer the fixed question, in this order: relevant candidate photograph → original source photograph of the sketch → actual sketch. The first step tests variation among photographs in a category; the second compares two depictions of the very same source. Align by Sketchy's verified source identifier **after** selection. Require that the source photo differs from both candidate IDs, belongs to the relevant class, and lies in the official gallery. No named label or source ID chooses a word or enters question construction. This is a diagnostic using privileged evaluation information.

For both the invariant and pooled question, report signed expected answers relative to the correct class on a −1 to +1 scale, and decision accuracy using the signed reversal certificate (ties count half). Evaluate the original photo and its sketch under both fixed source and fixed target prompt banks. This crosses depiction with template, allowing a direct test of whether wording alone accounts for an observed drop. Include the one-word dot-product retrieval reference, preserve the original orientation and replay the saved sketch verdicts. For the fixed sketch-template path partition the strict sketch errors into source already wrong, source formerly correct, and source formerly tied; disclose ties, repairs in the other direction, and paired class bootstrap intervals. Report differences in the signed answer as well as in correctness. Changing sources or prompts here changes a measurement, not a true causal intervention on human drawing behavior.
