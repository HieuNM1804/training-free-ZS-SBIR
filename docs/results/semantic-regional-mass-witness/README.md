# Regional evidence selects a partial semantic correction but does not eliminate the AP cost

The adaptive rule restored an average fraction of 0.261 on Ext-1 and 0.289 on Ext-2. After shuffling the same regional gallery scores across photos, the average fractions were only 0.021 and 0.028. Restoring word mass in the direction suggested by actual regional evidence changed mAP / precision from 84.373 / 84.103 to 84.040 / 83.888 on Ext-1 and from 77.774 / 75.433 to 77.678 / 75.468 on Ext-2. It gained/lost a top-200 hit on 29/3 and 43/1 queries. Coverage improved, while both splits lost mAP. The primary transfer criterion was not met.
