# Word rarity and GCWE confidence

The variance identity passed exhaustive enumeration. In the complete regional-plus-semantic context on 1,536 queries per split, GCWE as originally defined scored 84.308 and 78.500 mAP. Applying the word-specific precision estimate yielded 84.349 and 78.202. A single shrinkage coefficient matched for query-weighted RMS lift gave 84.328 and 78.209, and misassigning precision between frequency-adjacent words gave 84.441 and 78.308. The matched controls defeat the hypothesis that this null variance identifies useful word lifts. The no-GCWE control scored 84.130 and 78.106. Retain the original geometry update.
