# Geometry-guided query expansion as the nearest competing explanation

Spatial verification followed by query expansion is established prior art in object retrieval. Chum et al. use retrieved, geometrically verified examples to expand an instance query. Spatial verification has also appeared in cross-domain retrieval. A broad claim of inventing this sequence or introducing spatial verification to cross-domain search would duplicate existing results. [Chum et al., ICCV 2007](https://www.robots.ox.ac.uk/~vgg/publications/2007/Chum07b/). [Lee et al., ACM Multimedia 2014](https://doi.org/10.1145/2647868.2655045).

Content-free calibration has precedents in language and vision-language models. These include removing contextual answer preferences for a content-free test input and comparing generation probabilities for an image and its distortion. Candidate-specific spatial evidence in retrieval has a distinct observable but its subtraction operation alone has a close conceptual analogue. [Zhao et al., ICML 2021](https://proceedings.mlr.press/v139/zhao21c.html). [Leng et al., CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Leng_Mitigating_Object_Hallucinations_in_Large_Vision-Language_Models_through_Visual_Contrastive_Decoding.html).

Before the full-split scoring began, add a matched query-expansion comparison. Use the identical real-minus-canvas geometry, same donor set and selection weights, same fold and same gallery-word smoothing. Normalize the spatially weighted donor vocabulary to a distribution and interpolate it with the original query at feedback fractions of 10%, 50% and 100%. Keep every full-split result. This adaptation to our representation tests the simpler explanation that verified neighbors supply good words. It does not reproduce the original SIFT-based object retrieval system. The proposed estimator instead attends to whether a word is **enriched relative to its prevalence among the same visual nominees**. A claim specific to this update needs a consistent advantage over these controls. The locked candidate, parameters and held-out test are unchanged by these additional comparison rows.
