# Does the global semantic channel need the image directions named by CLIP?

Study Cross-Domain Semantic Retrieval by itself. Both CLIP prompt banks have 20,931 public Open Images words. The native score is the overlap of the sketch and photo posteriors, averaged over the two sketch views. Score both before and after the native RGB gallery diffusion. Use the first 1,536 positions in each Sketchy seed-42 permutation with the complete official galleries. This is a mechanism diagnostic on previously explored data.

Let μ and Σ be the empirical mean and covariance of normalized, frozen gallery image embeddings, and V be the eigenbasis of Σ. Use three sequential independent sign vectors from a seed-42 generator to define orthogonal reflections R = V diag(s) Vᵀ. Apply x ↦ μ + (x−μ)R to every sketch view and gallery image before computing its normal CLIP word logits. Keep the gallery graph fixed. The shared transform preserves all Euclidean distances and centered inner products among transformed visual features. Every gallery word logit retains its mean and all pairwise gallery logit covariances are preserved, including cross-bank covariances, since RᵀΣR = Σ. No post-transform renormalization: the object under study is the word logit distribution. Cosine relative to the uncentered origin and higher moments can change.

Compare the true axes with each common reflection, with separate commuting reflections on query and gallery, and with a common reflection that also restores each image's native softmax entropy by a scalar temperature. Entropy matching uses the native prediction for that same image solely as a control. The rotation can change higher moments, the locations of individual images, and which words dominate. This tests sensitivity to native image–word orientation beyond second-order gallery structure, rather than grounding every word. Include a visual cosine baseline using the same two views.

Primary evidence requires true axes to exceed all three jointly transformed controls in mAP on both splits, plus the entropy-matched control. Report query and gallery entropy, full covariance residual, paired intervals by class, raw and diffused scores, and the separate-reflection control. No TU selection or new retrieval component.
