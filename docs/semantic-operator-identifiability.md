# Which changes in the 64-neighbor gallery index can be made by editing the query alone?

This diagnostic replays the existing 601-word Semantic Dot baseline and the existing mean of 64 full-RGB neighbors per gallery photo. OpenAI CLIP ViT-B/32 stays frozen. Each sketch is read independently. Gallery labels enter the evaluator only. All configurations, the numerical-rank convention and the transfer direction are fixed before reading the results.

Let P contain the unmodified word distribution of every gallery photo, with one photo per row. Let W average the 64 other nearest RGB photos with equal weights. For a sketch distribution q, the original scores are Pq and the historical control gives Bq, where B = WP. Offline averaging of gallery coordinates and online propagation of these linear scores are identical. Keeping P fixed while editing q is a stronger restriction.

Write X = [1, P[:, :-1]] using probability rows of unit sum. Up to candidate-independent constants, its columns span all scores available from an unrestricted real 601-component query. Use thin QR and SVD in float64 to compute F, the orthogonal projection of every column of B onto the columns of X. Use only the standard numerical tolerance, machine epsilon times the largest matrix dimension times the largest singular value. Then B = F + R and XᵀR = 0. For every q, Fq is the least-squares solution for its own teacher score Bq, even if an alternative were allowed a separate nonlinear rule for selecting each edited query. Fq imposes no positivity restriction on the *edited* word coordinates. This is a statement about squared score error. Several distinct score vectors can induce exactly the same ranking.

Evaluate four fixed conditions with the original KD-SBIR implementation on the full unseen galleries: Pq, Bq, Fq and (P + R)q. The last two isolate the part of the 64-neighbor change available by editing the query and its orthogonal complement before ranking. The measurement uses proportions of centered squared change as well as full mAP and precision. AP is nonlinear, so the gains of the two interventions need not add. Check the per-query lookup of the projected index against an actual edit of the query on unchanged gallery coordinates.

Derive a single query map from the complete unlabeled Ext-1 gallery. Apply the identical map to the Ext-2 and TU-Berlin original word banks, with no neighbor search on the destination in that condition. Ext-1 and Ext-2 share some photos. TU-Berlin tests transfer between datasets for the same sketch-to-photo direction. The in-gallery projections for each destination are matched decomposition oracles. They tell us which scores that gallery's coordinates can reproduce and may use all its unlabeled photos. The historical 64 value was previously selected on Sketchy. No new method, hidden coefficients, positivity clipping, dictionary changes or search over k is involved.

## Follow-up on the overlap of the two Sketchy splits

After the full results were known, fix a descriptive test on Sketchy. In the already scored complete Ext-2 gallery, report the four classes with queries that also occur on Ext-1 and the remaining classes separately. Then match common sketch and photo IDs across the two splits. Keep every candidate and query identical and use the Ext-2 evaluator at 200 for both contexts. Change only which complete gallery was used to build the already frozen 64-neighbor or projected index. Check the native word coordinates on these shared items, count how many of each shared photo's 64 donors have the same dataset ID, and report top-1 and KD metric changes. This restricted-candidate comparison measures context dependence. Full-benchmark results are those in the main diagnostic. Code lives in `tf_sbir/semantic_operator_overlap.py`.

The restricted/full comparison motivated counting how many of the 200 retrieved photos, and how many top-1 results, come from the added photo pool. All added photos are irrelevant to the same four common classes. Labels verify this once the image scores exist. For each index, also count the share of these wrong top-200 slots occupied by the most frequent one percent of the added photos. The concentration percentage describes the rankings. It is never a ranking parameter.

The source edit admitted more new distractors. To check the extrapolation hypothesis on existing rankings, measure each destination candidate's unregularized statistical leverage in the source affine word design. Compute it by triangular solves in FP64 and verify the source leverage trace equals 601. For each identical query find the highest-scoring added candidate under each already frozen index. Compare this photo's leverage percentile among all destination photos of its own class, to account for different classes having different ranges. A larger paired percentile for the fixed edit than Semantic Dot supports an association with extrapolation. A similar or smaller percentile weakens that proposed explanation. This is an observational diagnosis and introduces no change to any candidate score.
