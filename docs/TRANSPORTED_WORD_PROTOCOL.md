# Transporting a reproducible change in the meaning of a public word

The previous two-word coupling is close to its independent control. It also treats each public word's meaning as fixed by CLIP, even if an unlabeled gallery consistently uses that word for a more specific visual phenomenon. The current hypothesis is that a word should change the query's interpretation only when independent reference galleries rediscover the **same associated visual mode**, and this local change must be transported between that word's photo and sketch prompts. This is a training-free inference step. CLIP is frozen and no sketch contributes to any gallery statistic.

Identify candidate lexical components using the existing maximum-likelihood prior on the full public vocabulary. The number of retained hypotheses is an exploratory hyperparameter, 48, 128 or 384, unrelated to the dataset's class count. On two disjoint random halves of the unlabeled gallery, initialize component responsibilities from literal CLIP photo-word evidence and that prior. Use a spherical mixture in the centered image space with shrinkage toward the initial word-specific assignments. All refinements are closed-form sufficient-statistic updates. Each evaluated gallery image receives its component probabilities from the opposite fit. The one shared initial lexical prior is estimated on all unlabeled photos, so the two complete procedures are not statistically independent.

For each word compare the cross-half cosine of the two corresponding centers with the most similar *other* center, in both directions. The smaller margin shrinks the proposed word correction towards its original prompt. This prevents swapping the identities of two competing names from silently becoming strong evidence. Calculate the word-specific displacement of the mean normalized gallery witness from its native photo prompt, remove the gallery-wide displacement and transfer the remaining variation. Specifically, $R_w$ is the minimum-angle rotation from the frozen photo word $t_w$ to the frozen sketch word $s_w$. For gallery estimate $\mu_w$ and common displacement $m$, map $R_w\,\mathrm{normalize}(t_w+\eta(\mu_w-t_w-m))$ to the sketch frame. The map can be computed as $I+A+A^2/(1+t_w^\top s_w)$, with $A=s_wt_w^\top-t_ws_w^\top$. The output preserves the inner product with the paired prompt before gating. At inference read the sketch likelihood using these adapted directions and marginalize it with each photo's cross-fitted component probabilities. Compare log-likelihoods with the historical word-plus-RGB-diffusion seed.

The component-only model using the exact same gallery fits and the original sketch word directions is the central comparator. Also optimize that model separately on Sketchy. Include the same-gated plain Euclidean displacement, shuffled word corrections, ungated rotation, assigning photos through a common fit, and visual centers without prompt transport. Full benchmark numbers must identify the portions due to gallery assignment, word transport and reference-fold stability.

Select mixture count, number of updates, amount of transport, query concentration, prior correction and share of component evidence on a balanced pilot from each Sketchy unseen split. Compare the leading candidates on all Sketchy queries. Freeze the winner and optimized untransported control before TU-Berlin with 30 classes. Store exact KD replay and matched differences. Two domains are named in the public prompt banks. The method requires paired word directions for the source and target domain, an unlabeled target gallery and no labeled source examples.

The word bridge and original gallery retrieval come from [FreeDom, WACV 2025](https://openaccess.thecvf.com/content/WACV2025/html/Efthymiadis_Composed_Image_Retrieval_for_Training-Free_Domain_Conversion_WACV_2025_paper.html) and [Wang et al., CVPR 2012](https://pages.ucsd.edu/~ztu/publication/cvpr12_CrDP.pdf). Shrinkage of directional mixture components in test-time inference has a close precedent. The proposed retrieval-specific mechanism couples an explicit per-word isometry to the repeatability of the same latent name across disjoint galleries. [Huang et al., ICML 2026](https://proceedings.mlr.press/v306/huang26ag.html).
