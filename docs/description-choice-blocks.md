# When does a frozen CLIP forward pass support a useful photographic description?

The WordNet pilot established that anonymously describing an object can retrieve its gallery class well when a label-informed selector has access to the entire bank. A sketch usually nominated less useful definitions than its source photograph. Changing the names attached to the sketch's two candidates did not improve either full Sketchy split. The visible-attribute study also found that recognizing a stated attribute within a class does not by itself fix real category errors. This retrospective analysis holds the original dictionary and model fixed and tracks category retrieval utility through an ordinary forward pass. It does not introduce an inference method.

## Subjects, alternatives, and controls

Use all unseen sketches on both Sketchy splits, their actual RGB sources, and the archived official KD-SBIR per-query candidate AP/P. No text choices, class names or samples are selected by this study using the final layer curves. Do not run TU for this exploratory diagnosis. Seed 42. Each readout is computed separately on an image. Additional sketches, source pairing and labels only enter retrospective controls and outcome evaluation.

- Compare the same two pair-redacted definitions from the original pilot on the sketch, its reflected view averaged with the original, a different human sketch of the same subject, its RGB source, a different source from its class, and a source from a different class. All readers use the same drawing prompt. Analyze every pair the query nominated, then exchange whole candidate pairs between sketches of different subjects within each class. This second panel removes the advantage of selecting the alternatives with the very representation under examination. A within-class derangement is bijective, preserving exactly the available score and utility pairs.
- Independently ask each readout to nominate from **all 1,135 senses**, including all 512 matched public nouns, as the pilot did. The direct first choice and the better of its first two distinct public heads are evaluated by looking up the exact full-gallery AP and precision in the previously archived canonical sentence table. The latter is a label-informed diagnostic ceiling. For this free nomination, a within-class permutation of whole source-photo choices must preserve mean category metrics. In the fixed-pair test the sketch's question does not move, so the matched source may outperform that same-class control.
- The primary scientific question is whether the last four blocks **erase** an advantage already accessible in the drawing. Predefine the boundaries after blocks 4, 8 and 12. A broadly useful erasure explanation requires both falling full-menu sketch nomination utility and falling AP for independent fixed-pair decisions from 8 to 12 on both splits, with paired class uncertainty supporting a decrease. Report all twelve block writes and do not choose the best layer or fit a fusion. The opposite pattern supports continued construction of task-useful evidence. A large source/photo advantage only on free nomination would localize a deficit in which descriptions are proposed, rather than in selecting between the same two. Unrelated photos and other sources of the same class distinguish general category evidence from exact subject specificity.

## Exact additive accounting

Use forward hooks to record the native CLS entering the first block and leaving each of the twelve blocks. Let h_i be a CLS, C subtract its mean across channels, W the released visual projection, gamma and beta the final LayerNorm parameters, sigma_i the LayerNorm standard deviation including epsilon, g_i = (C h_i times gamma) W, and a = beta W. With N = ||g_12 + sigma_12 a||, use y_i = (g_i + sigma_12 a)/N for bookkeeping. The input and twelve successive differences sum to the final normalized image vector in exact arithmetic. Dotting with the same difference of text embeddings gives a scalar contribution per block. Record the small additional numerical residual to the real native FP16 output and check agreement with the pilot. Applying a prefix in this accounting uses final normalization constants. Also report the independently normalized prefix (g_i + sigma_i a)/||g_i + sigma_i a|| at 4, 8 and 12 as a control. These are probes of a completed forward pass. They do not identify the effect of removing a block, since all later blocks read its output.

For fixed pairs report mean selected official AP/P, accuracy among pairs with unequal AP, and the mean signed cosine margin times the AP difference. The last statistic accounts for the magnitude of retrieval disagreement and has an exactly additive increment by block. Report paired class-bootstrap intervals with 10,000 resamples and class/source-balanced differences when comparing actual and substitute observers. Use the unmodified CLIP final output for the exact endpoint and include every query in AP. A frozen logit or an earlier prefix is not a contribution merely because it can separate some examples.
