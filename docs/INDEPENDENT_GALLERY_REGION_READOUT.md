# Separate the gallery that chooses a sketch region from the gallery that reads it

The original two Sketchy splits share 2,231 query sketches and 2,205 photos from four categories. With the sketch, relevant photo and irrelevant photo held fixed, the 64-name regional reader reverses 0.818% of comparisons on average when the surrounding gallery changes. The two 64-name banks contain only ten common names. The direct all-name reader is invariant but has a lower conditional pair accuracy. Wholesale elimination of gallery adaptation would discard useful information. The question here concerns which part of the adaptation to retain. [Diagnosis protocol](SHARED_GALLERY_DIAGNOSIS.md)

Disjoint subsets of the same unlabeled photo gallery provide independent reference panels for estimating the names and the visual prototypes. The candidates and the frozen RGB graph presented to every panel are identical. Build six panels by randomly partitioning photos, or by partitioning unlabeled visual clusters. The second design varies which groups of objects supply the names. For each reference, estimate the same likelihood prior and photo prototypes as in the original compact index. No target classes or test sketches select the references.

For a sketch and candidate photo, each panel produces a likelihood for each of the 13 regions in both image orientations. Normalize away a single scalar per query and panel. Let a_h be the distribution over regions chosen by the candidate using panel h. Let v_h be the corresponding vector of measured regional likelihoods. The ordinary bagged score uses the same panel to choose and measure. Its value is the average of the inner products of a_h and v_h. The proposed score averages the analogous products over all ordered *distinct* pairs of panels. This tests whether evidence for a region survives grounding that region with other source photos. The exact difference between the two estimates measures the part that depends on coupling region choice with the very same gallery fit. It vanishes if reference choice leaves region selection or region values constant. A sum-of-products identity evaluates all pairs using linear work in the number of panels.

Compare distinct-panel, ordinary same-panel bagging, independent draws allowing repeats, selection in one panel followed by the wrong spatial window, a uniform choice of regions and the original full-gallery index. A paired score-ratio intervention changes only distinct-versus-same coupling while keeping the strong historical score. Both donor partitions, several word capacities and candidate selection temperatures are available to the ordinary controls. Choose only on the two exploratory Sketchy splits. For a transfer use one configuration and evaluate all 30 TU-Berlin categories. This is separation of the vocabulary/prototype samples. The fixed RGB graph is shared, so unconditional statistical independence of every measurement is not assumed.

Double estimation uses separate evidence to select and evaluate an alternative and was studied for reducing maximization bias. The region policy here is soft, the references share a frozen gallery graph, and noisy regional evidence can carry genuinely helpful semantics. There is no theorem that distinct panels improve retrieval. Graph averaging and public lexical retrieval are the other mechanisms in the inherited base.
