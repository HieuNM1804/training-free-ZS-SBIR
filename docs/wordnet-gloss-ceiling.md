# Which stage limits the approved WordNet pilot?

This retrospective diagnostic uses exactly the text and images already covered by the pilot. First evaluate, for each benchmark class, the ranking produced by each eligible text against the full gallery. Every sketch of that class has the same relevance labels. The best AP over a bank of sentences is consequently the exact per-query ceiling for a selector that may choose **one sentence from that bank**. Compute the precision ceiling independently. The reference uses class labels only for this upper bound and cannot perform zero-shot selection.

Distinguish the 601 original photo-template nouns, all 1,135 anonymously redacted WordNet definitions, and the union of those definitions with all additional pair-redacted target strings actually encountered on that split. The union conditional on the observed pair list is an opportunity diagnostic. It is not the set of every conceivable renaming or sentence, and no query uses this joint pool during actual retrieval. Verify that the union contains both original pilot options for every query. Replay their metrics by lookup and compare to the original per-query pilot archive. Report floating-point rank drift separately.

If the bank-wide oracle reaches high AP but the two nominated options have low oracle AP, the first loss occurs by the time the sketch has nominated its two options. This observation alone does not distinguish a representation problem from poor gloss wording. Conversely a low bank-wide ceiling would reveal an additional limitation of using those sentences for RGB search. Keep the completed pilot and its decision criterion fixed. No alternative selector or retrieval configuration is fit or deployed here.
