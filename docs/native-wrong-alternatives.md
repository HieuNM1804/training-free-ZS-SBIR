# Do different objects of the same class elicit the same wrong alternatives?

Use the saved, unmodified CLIP ViT-B/32 visual embeddings and existing two-fold visual reference experiment. This is a retrospective error analysis. No mixed images, new image encodings, deployment rankings or parameter selection are involved.

For each focal class c and foil class d, remove **both** c and d from the same list of available rivals for every observer and every condition. A class comparison consequently cannot reveal its answer by the identity of the missing choice. Use each held sketch independently and weight each physical source equally within its class. Compare it with the actual strictly disjoint, non-source scoring gallery. The same reference subjects, 50 per class from the opposite fold, define the familiar visual class centroids. Separately compare the sketch with a drawing centroid per class, read the same source photos in the RGB domain, and measure sketch-to-sketch agreement between different physical objects. Centroids, focal classes and foils come from benchmark labels solely for diagnosis.

The primary observation is the identity of the highest-scoring remaining rival. Also ask a uniformly drawn pair of remaining rivals which one has greater cosine to the observation. For this second observation an exact tie casts a fair independent vote. For top choice, settle exact ties by the original frozen class order and publish tie counts. Report agreement for different objects of the same class and for different classes. Average the two orientations c and d equally. For probability vectors over the top wrong rival, same-minus-different is exactly one half of the dot product between the source class contrast and the target class contrast. A common preference for one rival gives zero difference if either side lacks a class contrast. For within-sketch agreement exclude all pairs of drawings of the same physical source, including the diagonal.

Prespecify two panels of class pairs. The first weights every possible foil equally for each focal class. The second chooses the most frequently preferred wrong RGB class for reference sketches of the focal class on the opposite subject fold. Apply this choice to held sketches and the non-source gallery, using the same hard pairs for every condition. Count each reference subject equally. A sensitivity analysis excludes the four shared class names from focal classes, foils **and rival candidates**, so the two development panels then contain disjoint classes. Preserve the original scoring gallery and use only eligible objects as observers of a given pair.

Also apply the same choices to the unfiltered public names already selected on each opposite reference fold. Use their original domain prompts for sketches and photos. Deduplicate public names, remove both focal names including all aliases in the class-to-name mapping that point to the same token, and evaluate the remaining distinct candidate names. Compare to native RGB and drawing-reference counterparts and the same-domain controls. This measures the contrast already present using words. It does not alter Semantic Dot or rank the retrieval gallery.

Report agreement as a probability in percent and its paired difference in percentage points. Average folds and then focal classes equally. Focal-class bootstrap intervals are descriptive conditional on the measured rival banks and foil choices. Publish fold-specific cosine tables, global IDs, reference and held source identities, hard-foil IDs and every unordered pair's measures. A repeated error pattern under the native encoder supports posing an intervention question. It does not establish that a perceptual interaction exists, that the errors contain new information over native cosine, or that any retrieval method improves mAP. Error patterns at object and image resolution have been used to compare visual systems. [Rajalingham et al., Journal of Neuroscience 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6096043/)
