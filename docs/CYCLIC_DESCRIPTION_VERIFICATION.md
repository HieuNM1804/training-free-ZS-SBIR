# Does a sketch preserve a three-way description preference that single words cannot express?

Only a small fraction of full-query rank-one mistakes had their true class name among the sketch's top 16 public words. Nevertheless an oracle choosing a single nominated name could recover many of those errors. A possible obstruction is that ordinary scorers assign a single scalar score to each noun, independent of the alternative against which the object is described. A pairwise preference generated by subtracting those noun scores always sums to zero around a three-way loop. The text encoder can also score two complete descriptions with the same words in opposite roles. This need not obey the same identity.

Build small panels of names proposed by each unlabelled visual group and its two nearest RGB rivals. For names a, b and c, encode complete descriptions in each domain with a and b interchanged. Examples of the fixed templates are "a sketch of a rather than b" and "a photo of a, with b in the background", where the two slots contain actual public names. Let D(a,b) be the difference between the two normalized text embeddings. For every triangle use v = [D(a,b) + D(b,c) + D(c,a)]/3. Any component of the form f(a) − f(b), including an arbitrary unary naming bias in either domain, cancels exactly. For a scalar image score the residual around its three comparisons is simply the image's dot product with v. Reversing the orientation in both domains leaves their agreement unchanged.

A residual in this algebraic sense can still correlate with responses to individual nouns across images. For each triangle, project its text direction away from the three individual noun responses using the covariance of unlabelled gallery features, separately in the source and target prompt spaces. This second, testable condition removes linear correlations with the three noun scores on those photos. Estimate the remaining direction's repeatability between a whole photo and its zoomed details, using opposite domain prompts. A query weighs its plausible names and divides each name's mass among the triangles it participates in. Every candidate receives the average agreement with the same query over these shared comparisons. No other sketch enters inference.

Term ordering and composition are established evaluation topics in Winoground. The contribution under test is whether agreement on *unary-invariant, target-checked* preference cycles contains cross-domain retrieval information overlooked by stronger word and region scores. Compare cycles from directional descriptions to the same experiment with a symmetric list of words, matched single nouns, and the transitive component of ordinary pair comparisons. Measure cycle energy, linear orthogonality, held-out repeatability, and the sign and magnitude of its change to the strongest regional baseline. The formulation makes no assumption that CLIP understands negation or that a nonzero cycle is a true scene relation.
