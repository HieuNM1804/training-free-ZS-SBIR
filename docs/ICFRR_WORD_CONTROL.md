# ICFRR control under frozen CLIP ViT-B/32

Run the test-time gallery reranker from Hudson and Smith on the same query and photo embeddings, public word bank, gallery size, split and KD-SBIR metrics. Use the authors' code defaults KQ=250, KG=256, beta=0.5 and five iterations. Record the initial result and iterations one and five. The RGB seed is negative Euclidean distance on L2-normalized CLIP features, matching the upstream score definition. Two adaptations use the raw word-matching seed and that same seed divided by the best photo score per sketch. These score-scale choices matter to a reranker adding a fixed bonus. They are fixed before this comparison. The stronger result on one test split cannot select a configuration for another.

The neighbor-vote computation is vectorized and any floating-point near ties are retained. Validate the full sequence of rankings against the authors' two original function definitions on four actual queries and 513 actual gallery photos per split. The source revision and SHA-256 are checked before use. This compares rerankers and seeds on the current backbone. Published numbers using the authors' trained backbone are a different experiment.
