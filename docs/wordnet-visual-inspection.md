# Blinded, qualitative check of the pictures behind the WordNet pilot

An analyst inspecting a drawing and two real photos can provide examples of visible distinctions after class metrics are known. This sample is not a human study or an estimate of generalization. No judgment is used to change a retrieval algorithm. All actual benchmark images stay out of the Git archive.

Use the original Semantic Dot's best photo of the true class and its best photo of a wrong class. Exclude cases where the true-class candidate equals the sketch's actual source, so the analyst cannot solve the task by matching the identical pose to its reference photo. In each split select six different classes for which both conditions exist. One example has both nominated definitions score the wrong candidate higher. In its paired control both definitions prefer the true candidate. Require a different source and two different candidate photos across that class's examples, and avoid reusing any gallery photo or sketch across the full blinded sample. Fix the ordering of choices by SHA-256 with seed 42, with available classes and queries in hash order. Use different classes across splits when possible.

Render four boards of six cases on Kaggle. Each row shows a sketch, a photograph A and a photograph B, with file names, class information, split and success/failure group withheld. Before revealing the key, the assistant records A, B or uncertain and a short visible reason for each row. Archive those judgments and the verifiable selection key, then count agreement with the class labels across all cases and separately for the two groups. Treat all descriptions as qualitative, from a single AI reviewer. Known class identity in Sketchy does not itself establish what attribute was deliberately omitted by an artist.
