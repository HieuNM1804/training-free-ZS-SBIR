# Does the same region support a word when retained and when removed?

A sketch can score highly for a gallery word through a local pattern which loses its meaning when viewed in context. In the compact public-word index, changing only the choice of the most useful word gave little consistent benefit on Sketchy. This experiment tests whether the missing information is spatial. All interventions use the current query, the frozen OpenAI CLIP ViT-B/32 and its original 7 by 7 patch locations.

For each of 13 windows, the visual transformer reads the retained patch tokens, then reads the complement. The CLS input and the positional embedding of each surviving token are preserved. A third forward pass encodes a resized view of the same rectangle. Use all placements at stride two for square windows of side three or five patches. These locations define the intervention. CLIP predicts their relevance independently for each word and sketch.

For a word, form a distribution over locations from the retained-word logits and another from the negative removed-word logits. Within a set of $n$ equally sized windows, call the distributions $k$ and $d$. Then $A=n\sum_r k_r d_r$. The exact average of $A$ is one over all cyclic shifts of $d$ relative to $k$. That finite null holds for every image and word. A high value identifies a location that is relatively sufficient for the word and whose removal is relatively damaging. Uniform responses return unit evidence. The result measures a property of model responses. Human object boundaries would require other evidence.

Use $k_rd_r$ to pool the third, zoomed-in CLIP readout. Evaluate the original whole-image likelihood alongside the regional likelihood and the factor $A$. Compare the joint signal to ordinary pooling of the same zooms, retaining only, removing only, and intentionally shifting the locations. Match the gallery, compact vocabulary and historical gallery interpolation in these controls. A large gain shared by the zoom-only control belongs to reframing.

Screen on 36 sketches per unseen class of each Sketchy split with seed 63241 and the complete gallery. Include the diagnostic best single window chosen using relevance afterwards to estimate room for better selection. This diagnostic cannot be used for retrieval. If a frozen intervention is competitive on both Sketchy splits, evaluate the strongest matched controls and main candidate on all queries. Select only by mean full Sketchy mAP then mean precision, and freeze before full TU-Berlin. Stage results identify pilot and full evaluation explicitly.

The perturbation draws on the sufficiency and comprehensiveness tests of ERASER. The new retrieval mechanism uses agreement over locations with an exact pairing null to decide how much evidence each public word should give a candidate.
