# Can the photo gallery tell a sketch which additional observation will resolve a ranking error?

When two sketches depict the same source photograph they can yield very different retrieval rankings. Recent experiments found a benefit from choosing regions separately for each candidate, while checking a region against its reflection reduced mAP on both Sketchy splits. These results suggest asking a different question before examining the detail. Given the competing interpretations of the whole sketch, which single zoom would actually change their order? An unsupervised gallery supplies a model of what CLIP could observe in each region under each interpretation.

Cluster the unlabelled photos by frozen CLIP visual features. Follow the global word retriever with a distribution over its strongest visual groups, computed from average per-photo evidence in each group. Split each group of photos into two disjoint panels. For every allowed crop and group, estimate a distribution of CLIP public-word observations in each panel. The decision criterion concerns the ordering of the latent visual groups. It is a proxy for category retrieval, whose benchmark labels are never exposed at inference.

For a pair of groups i and j with current probabilities pᵢ and pⱼ, the error cost before observing anything new is min(pᵢ,pⱼ). For an action r and possible observed word w, predict the order of the groups using pᵢ Cᴬ(i,r,w) and pⱼ Cᴬ(j,r,w) in panel A. If the first is greater, the expected error contribution on panel B is pⱼ Cᴮ(j,r,w), otherwise pᵢ Cᴮ(i,r,w). Sum over w and pairs, reverse the panels and average. The predicted value is the error before observing minus this held-out error. A proposed measurement earns credit only when the rival ordering predicted from some gallery photos is reproducible on others. In contrast, computing the minimum separately within one panel assumes its predicted decision boundary generalizes. For identical channels, all actions have value zero.

Once the action is chosen using the global sketch alone, read its region and update the ranking of the photographs. Compare the same lexical readout under this policy, the ordinary one-panel decision risk, Shannon information gain, one fixed gallery-wide action, a deliberately misplaced action at the same scale, and the exact expected score of one random action. Evaluate uniform pooling of all thirteen windows, the global-only system and the best post-hoc action for each query as additional bounds or references. The oracle uses labels only after retrieval and cannot be used as a method. Measure whether predicted improvements correspond to realized improvements for the individual queries. A large per-query oracle gap with no improvement over a fixed action would locate the failure in how the experiment is chosen.

The direct precedents are active observation selection, public-word retrieval and gallery diffusion. The proposed adaptation is to select an experiment across domains using independently replicated *pair-order decisions* from an unlabelled gallery. The regional grid supplies possible CLIP observations. It uses the same two scales in both image domains. The method is independent per sketch, training-free, and uses frozen OpenAI CLIP ViT-B/32. A pilot on balanced Sketchy queries precedes a full lock and a potential transfer test on all 30 TU-Berlin classes.
