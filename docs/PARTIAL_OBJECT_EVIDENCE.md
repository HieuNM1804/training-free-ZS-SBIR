# Can one unlabelled photograph explain several disjoint pieces of a sketch?

On the two complete Sketchy splits, selecting windows for a specific candidate improved over equal pooling. Selecting and reading a window using the same view was competitive with holding out the reflection. A different ambiguity remains: two overlapping windows may simply repeat one distinctive part, while a set of unrelated gallery photos may each support a different part. This study asks if multiple *nonoverlapping* clues could have come from the same photograph. Both the image and its windows are unlabelled.

Represent a gallery photo by the average public-word distribution of its 13 zoomed regions. Select a working vocabulary by the contribution of each word to the mutual information between a random zoomed region and its parent photo. Use actual source-domain text prompts to read each sketch window. Let $b_{rj}$ be the likelihood for query region $r$ under gallery photo $j$, divided by the mean over the complete unlabelled gallery. An uninformative region gives evidence one.

At cardinality $m$ enumerate all sets $S$ of $m$ disjoint windows on the native 7 by 7 patch map. The whole-photo partial-object evidence is the mean of $\prod_{r\in S}b_{rj}$. Mix cardinalities zero to four with a binomial prior on the number of visible clues, including the no-clue case. The prior equals one when all regional evidence is neutral. For a visual group $g$, average the evidence of its member photos. The control with independent gallery sources instead forms the product after averaging over photos. It can use a different photo of the same group to explain each region. The two models are identical for zero or one clue.

A separate spatial control samples distinct windows with the same number from every symmetry orbit as the real disjoint configurations. It preserves the cardinality distribution and the inclusion probability of every individual window exactly while allowing overlaps. Compare to explicit single-window evidence, the distinct-window control, independent gallery sources, and whole-photo target names. Compare a group readout with the evidence of individual gallery candidates. The input retriever remains the previous zoomed-sketch public-word gallery system. Only the two unseen Sketchy splits participate in selection. TU-Berlin uses a frozen system.

Flexible constellation models represent objects through visible parts in clutter. The adaptation here uses CLIP's own regional word responses and a tractable latent set of nonoverlapping clues. The controlled same-object test distinguishes actual gallery co-support from benefits of the extra zooms. No labelled object parts, gradients or extra model are used.
