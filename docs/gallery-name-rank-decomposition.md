# Where did the 64-neighbor change in ranks happen?

This retrospective diagnosis takes two already measured rankings for every sketch, Semantic Dot and its 64-neighbor gallery readout. For each ranking record the sequence of public nouns encountered down the rank list and a separate ordering of images inside each noun. This factorization is bijective. The public group is the name the photo independently nominated in the printed-word pilot, prior to rendering. It uses the released word inventory and stays fixed across both rankings, queries and controls.

Cross the noun sequence from one ranking with the within-noun image orders of the other. Fill each successive occurrence of a noun with the next photo from that noun in the designated order. Reconstructing a list from both of its own factors must return the original image IDs at every position. For a chance control, permute the photo-to-noun assignments before performing the same decomposition. This preserves every group size. Keep the same deterministic permutation for the entire split (seed 42). Labels enter only the original KD evaluator and paired uncertainty after forming every order.

If R00 and R11 are the original and smoothed metrics, and R10 only switches the noun sequence, the contribution of switching the sequence is half of (R10−R00)+(R11−R01). The contribution of switching the within-group orders is computed analogously. Verify their sum on every query. Also present the four raw tables. These are descriptive attributions conditional on a choice of grouping. The hybrids use both known rankings, have no independent information source and are not proposed as retrieval algorithms.

Run all queries from both Sketchy splits, use the existing KD rank replay with its source hash check and measure both official metrics. Reproduce the previously archived Semantic Dot and its 64-neighbor endpoint within 0.1 mAP and precision points before interpreting an attribution. A difference that can also be obtained with size-matched random groups cannot be ascribed to the linguistic identity of these names. No sweep or TU scoring.
