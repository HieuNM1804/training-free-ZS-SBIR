# Can a class description retrieve photographs outside the set that selected it?

The earlier full-gallery ceiling gave the selector both the benchmark class and the same gallery on which it was evaluated. A promising retrieval principle should predict performance on other specimens. The primary reference set here is the set of unique photographs with at least one actual human drawing in that split. The test set contains all remaining gallery photos. Reverse roles for a secondary comparison. Separately make one seed-42 random partition with exactly the same number of photos from each class in each side. Verify unique IDs, complete coverage, disjoint membership, stratified counts, and the mapping of every actual drawing to its source. This is an internal generalization test on target photos within a split, not an independent dataset.

Fix the 601 public names and all distinct canonical anonymous WordNet descriptions from the previous pilot. For each true category, the reference selector picks the single candidate with the highest original KD AP on reference photos, separately in each bank. Break ties by frozen inventory order. That **same** candidate supplies both AP and precision on test photos. Report target-oracle and reference-selection scores separately. The class is supplied to these selectors solely for an oracle diagnosis. Recompute two-view Semantic Dot on the identical test photos using all sketches. Also report the real top canonical description of each original sketch and of its source photo, with the original candidate IDs, as controls. The primary source-photo-to-other-photo test excludes the exact source of every sketch from the scoring gallery by construction.

For a lexical control remove all benchmark class names from the candidate inventory *before* either selection. This is a diagnosis of class-name overlap. Canonical spelling ignores spaces, underscores, hyphens and case. Remove a public name if it matches a split class name or shares a dictionary sense whose aliases include that spelling. Remove any definition of such a matching sense, including duplicate occurrences of that exact resulting sentence. All classes share one mask per bank and split. This does not remove all hypernyms, related objects, or other semantic clues. The full unfiltered bank and the unfiltered Semantic Dot reference remain visible.

Use all unseen Sketchy queries. Ext-1 uses mAP@all/P@100 on the indicated gallery. Ext-2 uses mAP@200/P@200 on that gallery. Comparing these scores with a historical full-gallery number would confound gallery composition and cutoff. Preserve exact query counts, class-weighted uncertainty, every winner, class-by-sentence table, and per-query AP/P. Encode photo queries with the existing frozen target prompt. Selection on reference labels and any same-gallery oracle preclude a deployable or label-free claim. A transfer advantage that disappears without benchmark-name senses does not support a mechanism based on independently discovered descriptions. A high filtered transfer score still leaves open how one sketch could discover the relevant candidate.
