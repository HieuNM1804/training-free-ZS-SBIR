# Does a candidate's appearance help after controlling for what that appearance does to every image?

Photo colors and textures can change CLIP's activations even when the depicted object stays the same. An independent per-sketch patch normalization failed in earlier trials. Here the intervention is indexed by a **candidate**. Estimate six unlabeled gallery style states using only the mean and standard deviation of ViT-B/32's 49 native patch vectors before positions are added. Squared Euclidean distance of the concatenated statistics equals the squared Wasserstein distance between the corresponding diagonal Gaussian distributions. No class labels, skeleton, masks or other sketches enter the procedure.

For each source image move its patch distribution partway toward each target style barycenter along the diagonal Gaussian geodesic. Keep every patch at its original position and pass the resulting tokens through the original CLIP transformer. Let $v_{qs}$ be the embedding of this intervention. On a fixed sample of 128 unlabeled gallery references, also apply the exact same style intervention and measure $m_s=\mathbb E_r[v_{rs}-v_r]$. The candidate-specific interaction is $v_{qs}-v_q-m_s$. An additive nuisance shift common to all input images cancels. It remains possible that the residual encodes a style-by-content effect irrelevant to retrieval.

For photos assigned to style $s$, use the interaction to modify the sketch's public-word likelihoods. Keep the underlying gallery word posterior and feature graph fixed. Rescale the modified seed mass within each style to equal the original seed mass there, so a choice of style alone cannot steal evidence for an entire subset of the gallery. Compare this construction with the same transform for every candidate, assigning the wrong styles, omitting the reference subtraction, replacing the intervention by its mean effect and removing mass conservation. Choose fractions and scale on the full Sketchy splits after a coarse pilot and transfer to TU unchanged. Each query is processed in isolation.

Adaptive instance normalization transfers channel statistics and has been applied to neural style transfer. StyleMeUp uses learned style invariance for SBIR. These precedents motivate the intervention. The candidate-specific difference in responses, negative-reference panel and style-mass conservation are the proposed retrieval mechanism.
