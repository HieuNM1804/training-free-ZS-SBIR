# Do the gallery measurements describe the same latent categories?

Individual named region relationships identified a photo under a mirror transformation about 89% of the time, yet identified a sketch's original photo against a similarly ranked photo of the same class only 52–55% of the time. Category retrieval could instead depend on relations shared by populations of photos. We test a property of a common latent-category explanation using only unlabeled gallery measurements. [Instance and category experiment](https://github.com/HieuNM1804/training-free-ZS-SBIR/tree/research/paired-concept-response-geometry)

For each photo obtain 13 local visual features with the frozen CLIP ViT-B/32. Average the two mirrored observations of each region. Let X and Y be features of two distinct uniformly sampled regions and let Z be the whole-photo observation. The empirical average of XYᵀ and YXᵀ over every distinct pair is computed exactly. A public name supplies a scalar h(Z) on the native photo. With M = E[XYᵀ] and T(h) = E[h(Z)XYᵀ], symmetrize both and whiten the positive part of M to a fixed dimension. This gives a matrix B_h describing how the moments change when gallery items receive different evidence h. The main measurement for a query uses its frozen full-gallery retrieval scores for h. One sketch can be evaluated independently.

Suppose disjoint views were conditionally independent given a latent category, with equal conditional means for X and Y. At the actual full component rank the whitened conditional means, scaled by square-root component probabilities, form an orthonormal basis. In that basis B_h is diagonal with the conditional category means of h. Every such operator commutes with every other one. Actual photo regions overlap, the query scores use a gallery index, and rank truncation can remove hidden states. Neither conditional independence nor identifiability of the benchmark categories is assumed in the evaluation. We directly measure whether operators for independent subsets of photos come closer to commuting than rotated references of the same spectral complexity.

Use three disjoint sets of photos, rotating their roles. The first defines whitening and the operators for public-name probes. The second defines B_q from the existing retrieval score of the current sketch. The third contains the candidates being evaluated. Candidate scores from the incumbent itself retain access to the original unlabeled gallery. No sketch enters any other sketch's calculation. Center probe measurements on the set where their moment is computed and explicitly preserve constant functions. Estimate the symmetric matrix X closest to B_q in squared Frobenius distance with a penalty on the average squared commutators of X with the reference operators. Center and normalize each reference first. The normal equation is linear and has a unique closed-form solution for nonnegative penalty. An eigenbasis of this quadratic penalty is indexed once per gallery fold. Every query then requires only a matrix transformation. Its trace stays fixed.

A held-out candidate with mean local features z in whitened coordinates receives zᵀXz/(zᵀz). In the noiseless identifiable pure-category model this equals the category expectation of the query evidence. In real data it is only a predictive score. Compare both replacing ordinary moment pooling and adding only the difference between filtered and unfiltered predictions to the incumbent. The tests include optimized unfiltered pooling, isotropic trace-preserving shrinkage matching the output's traceless norm per query, the same entire reference operator family rotated together by an independent orthogonal transformation, and a sign-reversed update. Rotation preserves all eigenvalues of the regularizer and all mutual commutators of the reference family; its orientation relative to the actual candidate is the specific quantity changed. Compare against a direct linear prediction from the same views as well. Choose parameters on the two exploratory unseen Sketchy splits. Use full-gallery KD-SBIR metrics. A leading candidate must justify its marginal value over ordinary pooling before transfer.

Observable operators and their shared eigenspaces in ideal three-view mixtures are established. The hypothesis under study couples a sketch's retrieval score to target-only public measurements through a common-state constraint, without estimating a list of dataset categories. Joint diagonalization and commutator penalties also have prior applications to multimodal registration. The three direct mechanisms in this study are observable moments, the frozen lexical base and its RGB gallery operator.
