# Is there category information in the allocation of a text preference across CLIP blocks?

The predeclared depth comparison did not support late erasure of useful sketch descriptions. This follow-up asks whether two pictures reaching almost the same measured endpoints still differ in how they arrived there. It is a retrospective diagnostic on existing forward passes. Candidate labels, real source identities and real redraws enter the diagnostic only. No new ranker is deployed.

Use every sketch and the same independent question from the preceding experiment. This question comprises two definitions independently nominated by a sketch of a different subject in the same benchmark class. For each query draw one isotropic direction using a seed-42 generator independent of the image content. Use unchanged directions for all observers and candidates within that question. A general retrieval system would not receive the question via same-class supervision.

The main positive is the predetermined different source photograph from the sketch's class. Match it with a source photograph of a different class, using three endpoint covariates over all eligible source photographs on the split. They are final native visual cosine to the sketch, final photo response along the text contrast, and final photo response along the isotropic control. Choose the negative with minimum maximum absolute percentile-rank discrepancy in the three covariates. Break an exact tie by the smallest sum of discrepancies, then by original photo ID. Report the observed balance and the performance of native visual cosine on the resulting pairs. The secondary identity panel uses the exact source as positive and another same-class source as negative. This design matches three scalar observations; other functions of the final embeddings can still differ.

Project the twelve CLS writes onto the question direction. Subtract the mean target-photo write at each block and remove each picture's mean write across the twelve blocks. This discards the component of the time series that is constant over depth, including its sum. Compute the resulting profile for the original sketch, its source photo and both candidates. Test which candidate has the larger cosine to the observer's profile, awarding half credit to ties. Compare with the same values sorted individually by magnitude order (ascending signed value), and with a single deterministic independent permutation of block identities per gallery photo. Add corresponding measurements for the isotropic direction on the exact same subjects and pairs. Numerically verify positive norms, IDs and matched covariates. Report every query and source/class-balanced paired intervals. Matching and all readouts are fixed before measuring performance.

A category-path interpretation needs the ordered text profile to outperform chance and both order controls on both splits. Also report it against native visual cosine and the random text direction. Alignment by block identity is still invariant to permuting both twelve-dimensional profiles together. Even a positive result would not by itself establish a noncommutative sequence mechanism, or +4–5 mAP over Semantic Dot. An exact-source benefit without a different-subject category effect will not be carried forward as a category retrieval method.

## Two-sided confirmation on the same queries

The first category comparison left native visual cosine with 67.20% and 61.70% accuracy after source/class balancing. This follow-up keeps each positive subject, question, random axis, observer, control and readout fixed. For each positive require one incorrect-class photo with a strictly higher final visual cosine and another with a strictly lower one. Select the negative on each side with the original joint three-covariate percentile matching and tie rules. A query whose positive falls outside the entire wrong-class cosine range has no bracket. Save its ID and availability and report coverage by class. Assign equal weight to the two sides of every retained query before averaging by subject and then by class. Native visual cosine must achieve exactly 50% for every retained sketch. Report the two side-specific accuracies and actual cosine gaps. This balances which side wins on the native cosine. It does not make the endpoint vectors or all covariates identical.

Test the already specified alignment against chance, sorting and the independent permutation with the existing paired class bootstrap on both splits. The random axis measures reliance on the specific direction supplied by the caption question. Also report the hard side, where cosine ranks the wrong photo ahead of the true category. A positive only when native cosine already ranks the true category first is insufficient evidence that the profile fixes retrieval errors. These are binary choices selected retrospectively using benchmark classes, not full-gallery mAP. No parameters are fitted.
