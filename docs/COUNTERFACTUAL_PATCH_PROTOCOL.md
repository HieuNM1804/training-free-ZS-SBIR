# Counterfactual CLIP attention for verifying retrieval witnesses

A shared word can point to photographs of different objects. The previous complementary-word experiment does not inspect any image again once the word profiles are fixed. We test whether the candidate features selected *inside* CLIP by a sketch-specific reader predict the same preference on both images. This hypothesis concerns the asymmetric amount of visible object structure across domains, and an individual sketch is sufficient.

At a frozen ViT block, take the native CLS query from a reader image $a$. Apply its native attention logits to the 49 RGB patch keys and values of a donor image $z$. Denote this readout by $R(a,z)$. Use only patch evidence for this measurement. For a query $q$ and candidate $i$, compute all four readouts $R(q,q),R(i,q),R(q,i),R(i,i)$. The two readers can differ systematically on photographs regardless of the candidate. Estimate their mean difference on a fixed unlabeled gallery reference panel and subtract it when comparing their choices on the two actual images. For each $z$ in the pair,
$$D_z=R(q,z)-R(i,z)-\mathbb E_{b\in G_{\rm ref}}[R(q,b)-R(i,b)].$$
The alignment of $D_q$ and $D_i$ measures whether exchanging the two native readers reveals the same direction in the patch evidence on *both* images. For any additive contaminant $f(a)+g(z)$, the two contrasts are exactly unchanged. A pair-independent feature cosine, global pooling and ordinary CLS attention do not test this interaction. The expectation uses target-gallery images only. Native and exchanged vectors share the same frozen key, query and value maps. There is no gradient, hand-drawn mask, edge detector or auxiliary encoder.

Compare with the same evidence without reference correction, the ordinary native patch descriptors, a fixed reference reader, and other readout controls. Use internal blocks 8 and 12 of the same ViT-B/32 to compare semantic and earlier structural evidence. Reuse the existing word-to-gallery score and RGB diffusion as the starting list. Test whether this physical verification changes which photographs are safe witnesses, as well as whether the changes survive original KD evaluation. Select settings on the two Sketchy splits only, freeze before evaluating TU. The candidate shortlist does not change the evaluation gallery.

Related work establishes that pretrained ViTs can rerank with patch matches, and that the final-layer residual can mask spatial signals in dense CLIP inference. The contribution under investigation is the native reader exchange, the gallery-reference subtraction and its use in independently verifying the witnesses for a vocabulary seed.
