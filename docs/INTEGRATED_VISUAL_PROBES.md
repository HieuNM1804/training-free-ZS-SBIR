# Do all possible visual measurements carry a common query-dependent state?

A 64-name reference family showed substantially smaller cross-sample commutator energies than an orthogonally rotated family, but the initial retrieval improvement was close to a tuned rotated control. A name read by CLIP is a linear measurement of a native image embedding before softmax. Thus many different probe dictionaries can describe overlapping parts of the same space. A specific question is whether rank performance benefits from the common structure of the full space of linear measurements after removing an arbitrary choice of named probes.

For each native gallery vector z, let h be its centered projection on a random isotropic direction. The observable matrix B(h) is linear in that direction. The expectation of the quadratic commutator penalty over all directions is therefore an exact sum over any orthonormal basis of the visual space. Compute its fourth-order coefficient Gram matrix once per reference partition, then obtain the full normal equation on symmetric matrices. This construction is invariant under changing the orthonormal coordinate system for the visual probe family. An additional condition whitens z on the calibration set before the same integration. Normalize the penalty as a whole to retain invariance to the coordinate system. Numerical comparisons to explicit commutators and to an orthogonal change of the entire probe basis are included.

All downstream conditions share exactly the same local target views, ranker, gallery partitions, moment model and complete original galleries. Alternatives use 64 names with individual energy normalization, only the leading visual axis, 16 visual axes, independent rotation of the regularizer, isotropic shrinkage matched to the output norm for each query and ordinary moment or linear pooling. The added operator for the all-visual condition uses photo embeddings alone. The inherited regional base uses the approved public dictionary. A score that improves on its base but ties ordinary pooling or arbitrary rotation does not establish a common-state retrieval gain. Closed-form whitening and commutator projection are gallery statistics. No benchmark category, fitted CLIP weight, or other sketch enters an individual query’s scores.
