# How much official mAP is available by correcting only one rival category?

Freeze the full original Semantic Dot order on every unseen Sketchy query. Treat one wrong category as the only type of photo allowed to move down. All other photographs retain their original mutual ordering. All category names, relevance labels and source information in this study are privileged diagnostic information. Compare with the official 64-neighbor readout on identical queries and galleries. No test hyperparameters or new retrieval rules are selected.

For each query and rival f, let r_j be the original one-based position of the j-th relevant photo in the fixed list. Let e_j equal r_j minus the number of f photos preceding that position. No allowed edit can retrieve the j-th positive earlier than e_j. On Ext-1 moving all f photos below the positives attains these earliest positions simultaneously. On Ext-2 the KD evaluator divides AP@200 by the number of **retrieved** relevant photos. Maximizing the number of positives retrieved need not maximize that AP. If the original and fully cleared top 200 contain h0 and hmax positives respectively, every feasible, non-worsening demotion has a count h between h0 and hmax. For any such h, placing all f photos in the prefix ending at the original h-th positive immediately after that positive realizes the earliest positions e_1,...,e_h, while the (h+1)-st positive keeps its original position beyond rank 200. For h=0 use the original ranking. The maximum over h of the mean j/e_j (zero for h=0) is an attainable optimum. In AP ties select the largest achievable accompanying precision. In ties between different rival identities use AP, precision, then lowest ID.
