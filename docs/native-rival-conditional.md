# Does a visual rival still carry a class contrast after fixing the public-name response?

For each pair let p_c(w), p_d(w), t_c(w), t_d(w) be the distributions of names in the two sketch and two photo groups. The independently sampled probability of an exact name match in a particular bin scales as a product. The minimum-mass weighting above instead measures a symmetric **standardized four-group contrast**. Its reported overlap is the maximum common one-observation mass of the four distributions, not the fraction of sketch–photo pairs that would independently match in name. Separately report the actual equal-class-pairing match frequencies with and without class agreement.

This is a conditional audit of the ordinary unmodified CLIP scores already measured. Use the prespecified hard focal/foil pairs and their already fixed common list of wrong alternatives. For each held object record its first remaining RGB class representative and its first remaining distinct public name, in the frozen drawing or photo template for its domain. Both focal and foil names are removed even if multiple class slots name the same word. The gallery contains no source subjects.

For focal class c and hard foil d, stratify sketch and non-source photo responses by the **same observed first public name w**. Within a stratum, require positive representation of c and d on both sides. Compute the symmetric excess probability that visual top rivals agree for objects of the same class over objects of different classes. Use equal class weights, equal physical objects within each class, and weight drawings from one physical object to sum to one **before** stratification. Weight each stratum by the smallest of the four class-normalized masses, so all four distributions are standardized to exactly the same public-name frequency in the reported contrast. Retain and report the sum of the minimum masses (common support), every class-pair result, the equal-focal-class mean restricted to covered classes, and the mass-weighted result.

Use the identical procedure the other way round, holding the first remaining visual rival fixed and testing whether the first public name still carries a class contrast. These comparisons hold only one observable categorical answer fixed. Any remaining contrast may be encoded in the underlying full score vectors of the controlled modality. Small common support limits the population for which an effect can be interpreted. Preserve the original reference objects, hard pairs, roles, device and frozen checkpoint. This study examines an empirical prerequisite. It supplies no query class or reference labels to a deployment method and does not produce a retrieval ranking.
