# Does a shared shift of sentence scores explain the sketch–photo choice gap?

Use the previously frozen lists of target-selected names and descriptions on the primary disjoint gallery. This audit fixes all candidate sentences. A source photograph represents the same physical object as its sketches. Work in the original drawing-prompt text space for both observers. Focus on the two-view sketch, report the source photograph and keep the category supplied to the reference selector separate from the information that a query could access.

Within each category divide distinct source subjects into two equal halves using a seed-42 hash. All drawings of one subject stay together. On the opposite half compute photo-minus-sketch menu logits per subject, centering across sentences and averaging drawings first. Estimate one global offset per sentence (equal class weights), a separate class-specific offset, and an offset from a different class in a fixed cyclic derangement. Apply to the untouched sketch scores of each held subject. Select one sentence and measure AP/P on the other photographs with the same original KD utility table. The offsets fit on real sketch/photo pairs and the class-specific row uses true labels, so all are diagnostic. Also transfer the offset observed from the other drawings of the exact same subject, reporting population coverage for this control separately.

For each held fold and each class identify the strongest rival in the opposite fold of actual sketches. Remove the true class's reference sentence and tally the highest remaining sentence with equal weight per distinct subject. Only compare categories whose reference winners differ. If several categories share a rival sentence, pick the lowest category ID for a reproducible diagnostic. Report every class pair separately as well as these difficult pairs, with equal class weights. For each pair calculate AUC for telling which class a drawing (or source photo) belongs to using the difference of their two sentence scores. Give each distinct subject equal total weight. AUC uses half credit for ties. Any constant offset per sentence is a constant shift of this two-sentence margin, preserving AUC exactly. This isolates changes in cross-subject order from changes in the common preference level. The AUC claims concern these sentences and this readout and cannot exclude other domain-invariant information in the original images.

## Pairwise operating points on disjoint subjects

A large AUC does not tell a single sketch which side to choose without an operating threshold. For every pair of distinct class-associated sentences choose the threshold maximizing the mean of sensitivity and specificity on the opposite subject half, with equal weight per true class and per source object. Use the midpoint of a score gap; among equally good thresholds choose the one closest to zero. Estimate all thresholds separately on true source photographs and on their human drawings. Always test on individual drawings from disjoint physical subjects. Count a tie at the threshold as half credit. Compare with the original threshold zero.

Project the matrix of antisymmetric thresholds onto differences of unary offsets by ordinary least squares on the complete sentence graph. With a threshold for every pair, its projection is the difference of the two row means. Measure how much of the squared threshold energy falls outside this additive form, how many directed choice cycles occur on held sketches, how often a Condorcet winner exists, and how often such a winner selects the correct class reference sentence. Evaluate full-coverage retrieval for the projected potential by choosing its maximum adjusted score. References, threshold estimation and the evaluation of relevance all use benchmark labels in this diagnostic. Use all sketches for the reported gallery size, with no source pictures in that scoring gallery. Differences between raw and projected pair performance alone do not establish optimality over all choices of unary offsets.
