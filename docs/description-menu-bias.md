# Does a shared shift of sentence scores explain the sketch–photo choice gap?

For each held fold and each class identify the strongest rival in the opposite fold of actual sketches. Remove the true class's reference sentence and tally the highest remaining sentence with equal weight per distinct subject. Only compare categories whose reference winners differ. If several categories share a rival sentence, pick the lowest category ID for a reproducible diagnostic. Report every class pair separately as well as these difficult pairs, with equal class weights. For each pair calculate AUC for telling which class a drawing (or source photo) belongs to using the difference of their two sentence scores. Give each distinct subject equal total weight. AUC uses half credit for ties. Any constant offset per sentence is a constant shift of this two-sentence margin, preserving AUC exactly. This isolates changes in cross-subject order from changes in the common preference level. The AUC claims concern these sentences and this readout and cannot exclude other domain-invariant information in the original images.
