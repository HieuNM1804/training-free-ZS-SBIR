# Mechanism control on the already observed category gain

The first full runs showed that category retrieval improves while same-class assignment of human drawings to their sources loses a small amount of accuracy on both Sketchy splits. This follow-up fixes the following retrospective decomposition before seeing its results on any dataset. Use the 601-dimensional reader and actual full64 donor graph, all benchmark queries, the same gallery and original KD evaluator. The oracle uses benchmark labels exclusively for decomposing two existing indices after both original rankings have been archived. The interventions are explanatory and cannot be used to perform zero-shot retrieval.

Let P_i be the native word distribution, B_i the existing 64-donor average, c the gallery class and m_P(c), m_B(c) their class means. Write each index exactly as class mean plus a centered deviation. Start from P and independently exchange (i) the means and (ii) the centered deviations with their counterparts in B. The four corners are P, m_B + (P−m_P), m_P + (B−m_B), and B. Record the two effects and the interaction on per-query AP; AP is nonlinear. Compute symmetric marginal contributions by averaging each component's marginal effect over the two possible orders, so the two add to the observed gain. This is a property of these specified counterfactuals, not a uniquely identified causal mechanism of CLIP.

As a stronger matched control, keep the actual final class means but multiply each original centered deviation by a positive scalar fixed by the ratio of the final to the original within-class Frobenius norm. This surrogate has exactly the same classwise mean and total squared dispersion as B. Its strictly positive class scale preserves all within-class candidate orders under every fixed linear query in exact arithmetic. The observed donor index can also rotate or displace individual deviations. A near-equal category metric would show that the category metric can be reproduced by a class-aware dispersion surrogate; a clear gap would show why a scalar spread is inadequate. These readouts are real vectors and need not be word probabilities. Report the endpoint reproduction against the archived run, trace and mean checks, all five category mAP/P values, class-balanced intervals, and the fraction of pictures whose within-class cosine residual and its donor residual point in the same direction. No fitted retrieval weights or further configurations.
