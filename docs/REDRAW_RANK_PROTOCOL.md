# Predicting whether a retrieval preference survives another drawing of the same object

A useful correction should affect the comparison for which a drawing is unreliable. Shrinking a whole sketch representation also weakens directions that distinguish its most plausible gallery matches. This study estimates uncertainty in the *difference* between two groups of photos using one sketch's own windows. It preserves covariance induced by scoring both groups with the same visual input.

Before developing the ranker, use repeated sketches of the same verified source photograph in Sketchy to check the premise. For each independently scored drawing, take its highest-scoring gallery group and the next four. Predict how often a different drawing of that exact photograph prefers the same group in each of these comparisons. Use other drawings exclusively to score these predictions retrospectively. Across Ext-1 and Ext-2, the nominal score margin gives weighted AUROC 0.723 and 0.690. Using the covariance of shared-view scores gives 0.759 and 0.759. Dropping the covariance gives 0.672 and 0.656. Reassigning an unrelated drawing's covariance in this retrospective test gives 0.743 and 0.729. These are preference stability statistics, distinct from retrieval mAP. All model scoring remains independent across queries.

For nominated visual gallery groups with whole-sketch strengths $s_g$ and a covariance matrix $C$ measured from that sketch's windows, estimate $v_{gh}=C_{gg}+C_{hh}-2C_{gh}$. The probability that $g$ ranks above $h$ for a repeat observation is modeled by $\Phi((s_g-s_h)/(\tau\sqrt{v_{gh}}))$. Include the diagonal as a tie. Their average over rival groups is an expected fractional rank. The matched reference uses the same scale $\sigma_*$ for every rival pair. Define $F(t)$ as the average of $\Phi((t-s_h)/(\tau\sigma_*))$ over the same rivals. Return the observed fractional rank to ordinary score units with the inverse of $F$. When all pair variances agree, this is the identity map, independent of the score distribution or the number of candidates. Shared additive score noise cancels from each paired variance. Redistribute evidence only across the nominated groups, keeping the total gallery evidence on that subset fixed.

Test two target group sizes and the entire set of 64 groups. Compare with ignoring inter-group covariance, a gallery-derived covariance independent of the input sketch, expected rank without the inverse calibration, an ordinary one-dimensional rescaling, and the input ranker. The pilot uses 36 sketches per class from both complete Sketchy galleries. Independently optimize the covariance-free alternative under the same protocol. Compare full Sketchy scores before locking the 30-class TU transfer.

Expected pairwise preference and uncertain ranks have precedents. The proposed retrieval operation measures co-movement caused by the same single sketch, validates it against genuinely different drawings of a fixed object, and inverts a matched reference rank to attach the correction to the existing image scores. The public word and gallery components are inherited.
