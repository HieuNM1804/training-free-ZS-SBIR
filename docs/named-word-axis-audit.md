# What is responsible for the gain from passing through words?

This is a diagnostic of the frozen Cross-Domain Semantic Retrieval baseline. All readouts below are fixed before seeing any audit rankings. CLIP ViT-B/32 and its released logit scale, seed 42, the 601 Open Images boxable nouns, the original and reflected sketch, and one RGB gallery view are shared. All official unseen sketches and photos enter the original KD-SBIR evaluation. The two Sketchy splits are exploratory. The same constructions and random transformations are fixed before TU-Berlin. No gallery graph, neighboring sketch, intervention inside the encoder, parameter sweep or fitted representation enters this analysis.

## Reading the original responses

For each view, compute CLIP logits against the existing noun prompts. L denotes subtracting the scalar mean of the 601 logits for that view. N denotes the existing softmax at CLIP's released temperature. The sketch readout averages the two view outputs **after** L or N. Compute raw dot products for all four sketch/gallery combinations LL, NL, LN and NN. A linear vector has zero sum, so centering a probability vector by the uniform prior in either mixed combination gives the same score in exact arithmetic. In NN, centering both probability vectors subtracts a common constant. Record the official visual cosine and the existing NN score. Also apply the same prompt to both domains, once using the existing photo prompt and once the drawing prompt. Use these as fixed template controls.

## Make synthetic coordinates while preserving the linear geometry

Draw three fixed orthogonal transformations from one seed-42 generator. They each fix the all-ones direction and act as a Haar change of basis on its orthogonal complement. Apply the same matrix to the sketch and photo logits before softmax, including both sketch views. This preserves the centered linear dot product of every image pair, each image's mean and centered norm, and all raw linear ranks in exact arithmetic. Verify orthogonality and dot-product equivalence in float64. A shared permutation of the noun axes serves as a positive numerical control. Log the SHA-256 of each transformation and use it unchanged on each split.

In a second control keep the **entire sorted final native word-probability vector** of each query and each candidate. Place its entries in the order given by that image's rotated probability vector. Apply this operation after averaging the sketch views. This matches every per-image order statistic, L1 norm, L2 norm, maximum and entropy exactly. The control changes which coordinates receive these values. It does not claim to preserve the nonlinear score or higher moments across images. Report all three rotations or their mean and range. No rotation is selected. The synthetic axes are mixtures of words, so this tests the value of the actual vocabulary axes under this particular readout without establishing human interpretability as the cause.

## Can words still distinguish photographs that agree on the obvious noun?

On the native baseline only, restrict each query's retrospective audit to photos whose most probable noun equals the query's own most probable noun. Within this group compare every positive photo to every negative photo and give half credit for a tie. Exclude a query from this conditional statistic only if either group is empty, and report its coverage along with the number of classes represented. Three scores use the same selected pairs. The first is the contribution of the shared top word, the second is the dot product of all other word coordinates, and the third is the original full dot product. Also measure native visual cosine for exactly those pairs. The conditional AUC averages over pairs within each query, then queries. A high AUC from the remaining words would support retaining textual distinctions when a noun alone is ambiguous. A negligible advantage over the first word would weaken that motivation. The conditional AUC is separate from official retrieval mAP and uses benchmark labels only after producing the representations.

For each official diagnostic save both per-query metrics, IDs, evaluator and text-bank hashes. Pair class-balanced bootstrap intervals with query-weighted headline differences. Rotation results remain individual replicates, not a ranking ensemble. The four-reference visual pilot was explicitly retained as a proposal and is outside this audit.
