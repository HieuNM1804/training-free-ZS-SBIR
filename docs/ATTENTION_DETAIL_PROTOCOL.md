# Recovering fine visual detail under the native attention distribution

Reframing sketches improved full Sketchy mAP with the frozen 32-pixel patch encoder. On Ext-1 ordinary zoom pooling scored 84.00 against 82.86 for the same native compact index. On Ext-2 it scored 76.43 against 75.95. The region deletion experiment explained only a small part of the improvement. The new question is whether a frozen 7 by 7 CLIP attention map can use the details inside each of its patches while preserving its view of the entire object.

Upsample the same native input by two. Encode the four quadrants as ordinary 224-pixel images, each through the same frozen visual blocks. In each native patch group the four finer patches by their actual image coordinates. At an intervention block the native query and native keys specify the pretrained attention mass $A_{im}$ of query token $i$ on parent patch $m$. The same query compares the four fine keys in that parent to obtain $W_{imr}$, a distribution over its children. Let $V^f_{mr}$ be their value vectors. The additional message to the original attention output of each head is

$$
D_i=\sum_m A_{im}\left(\sum_r W_{imr}V^f_{mr}-\tfrac14\sum_r V^f_{mr}\right).
$$

The coarse CLS self-message stays in the original forward pass. Each parent's mass in the fine readout is exactly $A_{im}$. Uniform child weights or identical child values produce zero correction. Averaging over the four cyclic reassignments between the fine keys and values within every parent also produces zero. In this sense the extra signal measures which details the frozen query selects beyond the mean detail of the corresponding patch. The residual proceeds through the original output projection and the rest of CLIP. The construction can be applied to a single input in any visual domain.

Compare against the native image, a whole-image 448 pass with interpolated positional embeddings, the four independent 224 quadrants, replacing coarse values with average local values, using fine keys to reallocate mass across parents, an incorrect key–value correspondence, and delivery of the same fine evidence to the wrong parent location. Check the native forward and the zero-correction identities numerically. The registered pilot uses the same 36 unseen sketches per class and complete galleries as the regional study. A positive high-resolution result shared by controls belongs to the additional scale. If the matched residual is competitive, select on both complete Sketchy splits, freeze, and evaluate TU-Berlin with the same setting.

The multiscale extraction follows the intuition of S². The retrieval system retains the prior public word and RGB gallery operators. The parent-mass constraint and the subtraction of the finite key–value permutation null are the proposed intervention.
