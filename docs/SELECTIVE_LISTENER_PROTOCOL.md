# A selective concept listener for a partial source observation

A sketch rarely depicts every attribute that CLIP predicts for a photograph. A linear lexical score regards the sketch as compatible with a random concept drawn from an image. A higher-scoring candidate can therefore be one with a narrow description even when a richer candidate contains a highly plausible explanation. We test a design for this asymmetry. Give a candidate several independent opportunities to explain the same query and ask how relevant the best expressed opportunity is. The observation model resembles selective communication under abstraction. It need not hold for every image or even every sketch. In particular, if a query supports exactly one word, the new score is monotone in that word's original probability and cannot change the ordering by that probability alone.

Let $u_w$ be the original positive sketch likelihood and $b_i$ a photo word distribution. The linear seed is $\mathbb E_{w\sim b_i}u_w$. For $n$ independent words from the same profile, score $S_n(i,q)=\mathbb E[\max_j u_{w_j}]$. Sort the query utilities $u_1\geq \dots \geq u_K$ and let $F_i(k)$ be the sum of this candidate's word mass over that query prefix. Then
$$
S_n=u_K+\sum_{k=1}^{K-1}(u_k-u_{k+1})[1-(1-F_i(k))^n].
$$
This integrates all explanations deterministically. For $n=2$, the difference from the linear seed is exactly $\tfrac12\mathbb E|u_{w_1}-u_{w_2}|$. It introduces a query-specific measure of heterogeneity in the candidate's semantic evidence. Exact bounded expectation is an elementary order-statistic identity. The research question concerns how an incomplete source depiction changes the appropriate likelihood on a target image, and whether its specific gain survives two tuned controls.

Use the already established full-public-vocabulary gallery prior to select 64 or 192 lexical hypotheses. The literal gallery posterior, the same posterior after the historical RGB operator, and an anchored gallery-centroid emission after that operator give the three gallery controls. Combine the resulting likelihoods with the original named word-plus-gallery diffusion score. The grid includes $n=1,2,5,12$, fixed strengths for the native query scale and the log-score mixture. The best independently tuned $n=1$ configuration is a competitor. Other controls change the explanation ordering to gallery frequency or an unrelated word permutation, flatten the photo-word marginal for $n=1$, or collapse the query evidence to a single winning word. The last condition can preserve aspect confidence while losing most semantics. Validate the exact integral against all word pairs and triples in small real profiles.

The design is exploratory on the two Sketchy splits. Search a balanced query sample, compare three nonlinear and two linear candidates on every Sketchy query, then lock before 30-class TU. Every final condition replays the original KD metrics. It uses the existing public word bridge and gallery diffusion. Fan et al. show that people vary the information made explicit in drawings according to communication demands. Trainable pragmatic sketch-production models do not imply that human drawers literally draw a fixed number of terms. Concept ordering and its probability integral are a hypothesis for retrieval with frozen CLIP.
