# Does a gallery ambiguity survive interpolation inside CLIP's text encoder?

A probability mixture of possible public words and a single soft string can have different meanings. Existing word retrieval uses a mixture after the frozen text encoder. This study constructs a gallery-conditioned object span before the encoder, and checks whether using that span is justified on different, unlabelled photos. A soft span is a deterministic representation of the candidate. No token or prompt parameter is learned.

Build 64 visual groups from gallery RGB representations. Split the photos into two random panels. One panel proposes the 8 or 24 highest-mass public names of each group. Partition those names by actual BPE span length. Only mix inputs that have identical template prefix, suffix and EOT position in both photo and sketch prompts. Names with incompatible boundaries retain their ordinary readings. Within a compatible bucket, replace every object-token embedding by its weighted average at the same position. Preserve the pretrained input positions, transformer and projection. Singleton mixtures must reproduce the corresponding unmodified prompts.

For a word bucket with weights $a_w$, compare the ordinary emissions $L_D(x)=\sum_w a_w\exp(\tau\langle x,T_d(w)\rangle)$ to the single emission $L_F(x)$ produced by its soft object span. On the disjoint gallery panel compute the difference in held-out log probability for the proposed visual group. Normalize both emissions over the *entire* held-out gallery, so a generic span cannot pass solely by scoring every photo more highly. Use that validation gain to set the probability of replacing the discrete interpretation. Then exchange the panels. The query uses the sketch-domain prompt with the same span. Both panels can be computed before a sketch arrives.

Compare against the exact mixture of individual words, a normalized average of their output embeddings, unconditional span interpolation, a local gate that skips gallery-wide normalization and the reversed verification signal. Evaluate the incremental change against the existing regional baseline as well as the two complete group scorers. A useful contribution requires evidence that successful photo validation transfers to sketch retrieval. The pilot uses 36 sketches per unseen class and the entire corresponding Sketchy galleries. Never nominate terms from benchmark category names.

Textual inversion as an input to a frozen CLIP text model has prior art. SEARLE uses optimization and trains a predictor for its faster variant. The current construction uses only genuine BPE spans from previously authorised public names and a disjoint-gallery comparison between two interpretations of the *same* probability mixture. FreeDom and RGB gallery diffusion supply the other two direct mechanisms.
