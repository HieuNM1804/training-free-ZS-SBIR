# Where does a known true sentence lose a gallery decision?

The first measurements show that good relative attribute discrimination can coexist with poor retrieval using an individual sentence. Diagnose this on exactly the same eight eligible classes, subjects and opposite-state photo pairs as the source-excluded retrieval readout. Scores and judgments remain frozen. This is a post-hoc comparison with a known two-caption identity from prior work and is not a proposed retrieval algorithm.

For one photo of state A and one of B, define ΔA as the score difference between the two photos when read with caption A. Define ΔB analogously for caption B, again in A-photo minus B-photo order. The shared term b = (ΔA + ΔB)/2 measures the preference for one photograph common to both captions. The distinguishing term h = (ΔA − ΔB)/2 measures their relative ordering across the two photos. The margins for the correct photo given the true captions A and B are h+b and h−b. The four outcomes are both correct, both wrong, and either member of the pair winning for both captions. Split ties evenly.

With the true caption given and a balanced choice of state, subtracting the shared term gives exactly the AUC for the photo margins on the same classes. Keeping the photo contrast but letting an individual sketch decide which state to send tests the practically important second condition. Compute the corresponding native sketch/candidate accuracy, terms for every class, per-pair exact identities and the class-balanced post-hoc differences. Compare the isolated and both orders of true and neutral context without selecting a configuration. All property texts and their exact opposing alternatives were supplied by a reviewer. Their availability at evaluation time is part of this diagnostic.
