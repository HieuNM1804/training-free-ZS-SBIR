# Fixed-pair audit of the final visual projection

The block-6 study found better patch agreement for correct and incorrect categories alike. A separate observational question is whether CLIP discards class-discriminating evidence before the Semantic Dot baseline can read it. IsoCLIP analyzed the image and text projectors in intra-modal retrieval and compared against unprojected image features. Here the measurement is the part exactly erased by the actual B/32 visual projector on archived errors of a fixed different reader. Neither taking the preprojection vector nor factoring the projection is a new method. [IsoCLIP](https://arxiv.org/html/2603.19862v1)

For every unseen sketch on both Sketchy splits, keep the top correct-class photo and top wrong-class photo previously selected by Semantic Dot after exclusion of the original source image. Verify the SHA-256 of those archived pairs. Run the frozen vision encoder on the paired photos and the query with its standard mirrored view. Read the final class token after LayerNorm. Decompose it into the projector's retained 512-dimensional subspace and its orthogonal 256-dimensional nullspace. Test both, the complete preprojection feature, the native projected image feature and a seed-42 random 256-dimensional subspace drawn inside the retained subspace. Use unit-norm vectors, normalize before averaging reflected query views, and compute the signed difference between the two cosines. There is no threshold or coefficient selected on this panel.

Report the fraction favoring the correct-class photo among previous Semantic mistakes, among its correct choices, and across all fixed pairs. Use equal query weight for prevalence and paired, equal-class bootstrap intervals for differences between the discarded and random retained controls. Show whether the retained and discarded spaces disagree on a useful subset. Check that the discarded coordinates have negligible projection through the native head and that the native readout replays stored cosine differences. These measurements describe fixed pairs selected by Semantic Dot. They do not evaluate a gallery ranking. A positive result by itself would establish neither conditional independence from the retained representation nor a novel algorithm.

## Do actual human redraws repeat the decision?

Fix the identical endpoints. Keep focal queries where Semantic Dot preferred the distractor, the actual source photograph in photo-side word coordinates preferred the correct-class photo, and at least two other sketches of the same source exist. For each focal query compute the exact probability that two *other* drawings sampled without replacement both prefer that same distractor. Compare with first choosing a different source uniformly from the same class and then taking two drawings of that source. The competing photographs and the number of drawings compared are identical throughout. Average queries within a source, sources within class, and classes equally. Report class-bootstrap intervals. This tests whether the choice error repeats for a particular depicted subject beyond a class and candidate preference. This test cannot isolate which details humans omitted or identify the artists. Source identity and other test sketches are available only to this retrospective baseline analysis. Research on human drawing motivates testing which changes are shared across people and which are specific to the intended referent.
