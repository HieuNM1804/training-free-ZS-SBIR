# Predicting held-out concept responses across depictions

A regional scorer calibrated by separately sampled target galleries improved Sketchy Ext-2 with one random partition. Two fresh partitions gave 80.61 and 80.57 pilot mAP, compared with 81.09 for the original and 80.63 for the unchanged baseline. On 2,231 identical sketches and 2,205 identical photos, its correction increased cross-gallery rank reversals from 0.60% to 1.35%. The question below is whether a sketch and a candidate photo can support a reproducible account of their apparent difference using measurements of the two images themselves. [Original split and seed controls](https://github.com/HieuNM1804/training-free-ZS-SBIR/tree/44fbc1b/docs/results/gallery-stable-region-evidence)

For each public name, measure the same image twice against CLIP's source- and target-domain descriptions of that name. The current query nominates names with its frozen source-prompt scores. For those names, let x contain the query's source-prompt responses and y the candidate's target-prompt responses. The vector u is the change in the query’s responses when reading the same names with target-domain prompts. The vector v is the change in the candidate’s responses when reading them with source-domain prompts. All four vectors come from native frozen CLIP forward passes. Each candidate can therefore propose different changes that might reconcile the two observations. These changes are finite differences in how CLIP reads language. Whether they trace a real visual nuisance is an empirical question.

For a pair, predict the discrepancy r = x − y with an intercept and the two observed directions. Each name is predicted with its own response omitted. The estimate for one held-out name is obtained by solving a two-coordinate ridge problem on the other names. With a fixed ridge penalty and unpenalized intercept the deleted residual equals the in-sample residual divided by one minus its diagonal leverage. Compute all held-out errors with a single two-by-two inverse for the pair. This is a closed-form distance, with no gradients, weight updates or fitting across query images. It also gives a direct test of whether an explanation inferred from some names predicts other names of the two images. Synonyms can still make different lexical coordinates statistically dependent.

Score all candidate photos with the negative log of the root mean squared omitted-name error. A second intervention adds only its log improvement over the same held-out intercept-only model to the strong regional baseline. The latter isolates the correction from the native semantic distance. Since word nominations depend only on the sketch, every pairwise correction is exactly independent of other gallery members up to numerical precision. The existing frozen retrieval score in the combined system retains its gallery dependence.

Test 16, 32 and 64 names, two ridge penalties, and common scoring strengths. Compute the error of in-sample fitting, an intercept alone, fixed middle-of-prompt contrasts, source-only and candidate-only directions, and assigning target prompt changes to unrelated nominations. Give the comparison systems their own tuning budget. Evaluate which of matched relevant and irrelevant images is favored among adjacent opposite-label pairs in the baseline top 200. Actual category labels are available only after all scores are computed. Equal-weight mAP on the exploratory Sketchy splits selects conditions. A transfer evaluation uses all 30 TU-Berlin categories after locking. Dependence on the public dictionary and the source/target descriptions must be disclosed.

Simard, LeCun and Denker compare observations up to locally parameterized transformations. Here the measured directions are image-specific changes in semantic responses to the same names and the proposed quantity is prediction error on omitted coordinates of the individual image pair. The retrieval base inherits public-domain word matching and RGB gallery diffusion.
