# Does the depiction change the object name inside the frozen text encoder?

The same public noun receives different CLIP text embeddings in “a sketch of the …” and “a photo of the …”. A full Sketchy experiment found that amplifying an image-specific component of this gap can improve retrieval on the two exploratory splits. Directly extrapolating the entire prompt changes style and object content together. This experiment asks which part of that change traveled through the *states of the object name itself*. This is a different claim from an observation that the two prompts have different scores. [Full preceding sign experiment](https://github.com/HieuNM1804/training-free-ZS-SBIR/blob/c8b2ce1/docs/results/paired-prompt-head-intervention/FULL_VI.md)

At a chosen depth in the frozen causal CLIP text tower, take two natural prompts containing identical name tokens at identical positions. Exchange just the hidden states corresponding to all BPE pieces of the public name. Complete every remaining transformer block. The other intervention exchanges the complementary states, including the depiction prefix, punctuation and pooled end token. The four combinations have outputs T, N, C and S, respectively all-photo, noun-from-sketch, complement-from-sketch, and all-sketch. Do this for both established prompt pairs, average the two unit representations and normalize for each combination separately.

The symmetric contribution carried by the hidden name states is n = ((N − T) + (S − C)) / 2. The complementary contribution is c = ((C − T) + (S − N)) / 2. The sum is exactly S − T. The quantity S − C − N + T measures an interaction and distinguishes effects measured with different backgrounds. At the input there is no change on swapping the identical name tokens. At the last block, swapping only the noun cannot change the separately pooled end token. Intermediate effects must be measured in the actual model. The swaps intervene on this encoder's representations. They alone cannot establish what a human meant by a drawing.

Test the resulting public word directions with frozen sketch embeddings and the same unlabelled photo gallery. Contrast name and complementary paths at equal or independently tuned strengths, against the full prompt gap, a collinear norm-matched direction, a mismatched public name, and the direct single-background intervention. No test category names take part in selecting names or modifying the text bank. The previous regional retrieval score and pixels are the reference. Pick by equal-weight unseen Sketchy mAP and then precision, with original KD-SBIR scoring and a transfer after configuration lock if the evidence warrants it.

Basu and colleagues intervened on token states to trace visual attributes in a text-to-image model. Their localization finding concerns that generative system. Here we exchange states between two well-formed captions and measure ordinary contrastive retrieval using OpenAI CLIP ViT-B/32. The intervention precomputes public textual directions independent of every query and benchmark. The training-free word bridge and the RGB gallery operator are inherited.
