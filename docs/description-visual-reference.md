# Separate recognizing the source category from representing it on target photographs

Use the disjoint test gallery of photos without human drawings, with exactly the same queries and KD metrics as the sentence study. Class labels on the reference subjects are privileged oracle information. No benchmark class names or WordNet text are supplied to the visual controls. This directly tests whether the problem is inherent in selecting a single class or in using the same sentence to recognize and retrieve it.

Alternate the two fixed subject half-folds. For each class construct its unit photograph centroid from only the opposite 50 source subjects. Construct a drawing centroid from the drawings of exactly those subjects by averaging normalized two-view representations within each subject first, and then averaging subjects equally. For each held sketch, independently choose the most similar reference class centroid by cosine. Also record the analogous choices of its own source photo and class-informed ground truth. A lower-cost single-example reference (deterministic seed-42 choice per class) and a class-size-preserving independent reassignment of reference subjects are controls. No held query or its source may enter a centroid or the selection of target sentences.

Cross the predicted category with different encoders for the target gallery. A category retrieves the gallery with either its held-reference RGB centroid, its best filtered canonical description on those same opposite-fold photographs, or its best unfiltered public name. Select each text by original KD AP on the reference photos and use the selected string for both held target metrics. As additional source-side comparisons, the same names and filtered descriptions with the fixed drawing template can predict the category. The target gallery is never used to construct a centroid or to select a descriptor. Use direct original KD scores for each selected vector on actual other-gallery RGB features when aggregating outcomes. Publish every cell of the cross, per-query category decisions, class-balanced accuracy, paired gains, counts, and the largest discrepancy between the archived matched-gallery Semantic Dot and this readout. No hyperparameters are chosen.

Normalize the drawing mean for each reference subject before averaging subjects, so a subject that has several inconsistent drawings retains the same coefficient as the others. Drawing centroids require other labeled sketches, RGB class centroids require labeled reference classes, and a category oracle provides the true query class. All three are retrospective diagnostics outside independent zero-shot inference. Their scores cannot be presented as a proposed retrieval method. A gap that disappears on removing true class assignments would diagnose which kind of supervision a follow-up needs to replace.
