# Does frozen CLIP read category agreement between two depicted objects?

The gallery rank audit found that preserving target-category composition reproduced the apparent effect of public noun groups. This diagnostic asks whether CLIP itself contains usable evidence for a category relation, using neither public nouns nor category names in its readout. It is a controlled assignment task with oracle construction of trials, not a new retrieval system.

Use all unordered pairs of unseen categories in each Sketchy split with four seed-42 trials per pair. Pick one photo from each category and a sketch from a different source in that category. Sample source identity before choosing among its drawings. Also construct a difficult panel when a noun occurs among the photos of both categories. Choose a shared noun uniformly and one photo with that noun from each side. Use identical sketches in the ordinary and same-noun conditions and exclude both selected photos when choosing the source of each sketch. Choose all images without using the relation scores.

Create four boards showing the four possible sketch/photo pairs. In the correct assignment both boards pair different individuals of the same category. In the crossed assignment both boards pair different categories. Both assignments contain exactly the same four pictures. Two 112×112 thumbnails on a white 224×224 board have fixed size and position. Evaluate both left-right orders, then average the two signed assignment margins equally. Use a single fixed difference between the normalized text embeddings of "two objects of the same kind." and "two objects of different kinds." No benchmark word is in either prompt.

Read native CLIP cosine to the text contrast. Also measure the raw projected visual feature before its final L2 normalization. Compare with replacing the pair embedding by the sum of its two single-panel embeddings minus the all-white board and then normalizing, controlling for effects explained by independent panels and output normalization. Every additive scalar function of the two panel identities cancels exactly in the assignment contrast. Verify this identity before interpreting the normalized-additive control. Report ordinary CLIP visual cosine on the original images, the two orientations individually and the subset of trials on which ordinary native cosine chose incorrectly. Every score here is measured across paired trials and does not estimate mAP.

Report equal weight per category pair, paired uncertainty by resampling the category identities and reweighting the incident pairs, and coverage of the same-name panel. A candidate-independent category reader would need the single frozen text question to beat chance and its matched normalized-additive control on both splits, also on the same-name subset. An apparent average gain from one orientation only is insufficient. The name tags are used for constructing a control only. Even a positive diagnosis would require a separate authorized, efficient, independently verifiable algorithm. [Winoground, CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/html/Thrush_Winoground_Probing_Vision_and_Language_Models_for_Visio-Linguistic_Compositionality_CVPR_2022_paper.html) · [Beyond the Doors of Perception, NeurIPS 2024](https://papers.neurips.cc/paper_files/paper/2024/hash/ed99503856b2ba85092e5413add65d86-Abstract-Conference.html)

Before interpreting the primary result, apply two positive controls to the exact same trials and question. First replace each sketch by its own source photograph. This preserves both underlying objects and leaves different individuals on each correct board, but both panels are now photographs. Then use the candidate photograph itself in the observer slot. This tests sensitivity to literal image repetition. Strong performance only on duplicated images would provide evidence of a repetition cue, not general recognition of shared category. The image IDs of the primary trial remain archived for all three readers.
