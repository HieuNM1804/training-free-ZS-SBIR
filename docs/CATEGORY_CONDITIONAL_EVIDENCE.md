# Same-exemplar evidence versus independent category witnesses

The current regional retrieval score supplies two kinds of evidence for one sketch. Its full-image lexical score can be strongest on a photo that depicts the right background or accessory. Its regional score or native visual cosine can favor other photos from the same subject. A single shared linear gallery operator applied to the existing score cannot measure how two different clues covary inside the hypothesized category. We start by isolating that distinction on actual retrieval errors.

Convert each independent sketch-to-photo score to the fraction of gallery photos it outranks, with half weight for tied scores. For a hidden category c and two clues a,b, the expected product E[ab|c] measures two successes on the same photo. The product E[a|c] E[b|c] measures successes on two separately drawn photos of the category. The difference between them is minus the within-category covariance. For a finite class population of size n, the exact average over distinct ordered pairs of photos is (n E[a|c] E[b|c] − E[ab|c])/(n−1). This comparison uses identical single-clue distributions. Both probabilities are unchanged by strictly increasing transformations of either initial score.

The first experiment reveals true gallery categories only for diagnosis after the native, lexical and regional rankings have been produced. On every actual misretrieval, retain the true category and the wrong category of the frozen ranker's top photo. Ask whether separating the witnesses favors the true category, whether it changes which category wins, and whether the result beats the arithmetic average of the two single-clue probabilities. Repeat with the full ranker as the first clue and native cosine as the second, and with whole-image and regional lexical evidence. Compute comparisons against all categories as a second diagnostic. These are oracle category diagnostics, not deployable retrieval scores.

In a three-view latent class model with a shared orthonormal observable-state basis, the product of two observable operators has as its category coordinate the product of their conditional means. The operator measured from the product of the two signals instead has the same-exemplar conditional moment. Their difference allows a sketch to make a genuinely two-clue intervention on an unlabeled gallery. The underlying operator multiplication is established. The proposed retrieval use is the counterfactual of drawing two different exemplars to support one sketch's clues and a test separating that mechanism from ordinary class pooling. A larger gain from class pooling alone must not be attributed to changing the witnesses. Test the category premise first, before treating the operator estimate as a solution.
