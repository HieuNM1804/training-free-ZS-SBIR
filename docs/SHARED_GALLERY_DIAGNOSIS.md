# Does the same sketch–photo preference survive a change in gallery composition?

Use the original two Sketchy splits exactly as distributed. Match sketch and photo paths between splits. After scoring their complete, separately indexed galleries, restrict a diagnostic to the common queries and common candidates. Compare every relevant–irrelevant candidate pair for each query, using the same category labels attached to the same files. Record the fraction that reverse, correct in both contexts, or incorrect in both. Also record the fraction of shared top-100 photos and consistency of the top image and its class. The primary measure weights common queries equally. Raw pair counts are available separately. Changes in benchmark AP across the two splits do not identify this effect because both the candidates and the official metrics differ.

The original cosine between two images and direct lexical scores computed without gallery-dependent normalizers should be exactly invariant. Direct use of all public words for both gallery and query is another negative control. Repeat the same comparison with the historical global RGB retrieval operator, the 64-word regional index, and the complete locked regional score. Test the effects of changing the word set alone, retaining the full dictionary, and holding the regional normalizer fixed. The last normalizer uses both existing galleries solely as a diagnostic. All other readers build their statistics separately inside each original gallery. This experiment changes only how already authorized images are compared and aggregated. It does not pool unseen sketch queries, obtain external labels, or introduce a new retrieval dataset.

The proposed next question is whether a reproducible semantic explanation for a region can preserve discriminative information as the available gallery changes. Physical invariance of rankings is a diagnostic property. A useful retrieval method must still improve official retrieval metrics over the fixed regional baseline and suitable simpler controls on full galleries. All labels, shared path matching and comparisons between gallery contexts are confined to the retrospective sensitivity analysis.
