# TU-Berlin check fixed after both exploratory Sketchy splits

The first Sketchy analysis is complete. On native visual top-1 errors, the class-balanced probability of a correct crossed assignment is 94.67% and 91.28%. Comparing against unrelated drawings gives 79.64% and 74.85%. When both endpoint classes belong to only one split, the probabilities fall to 82.38% and 76.29%, while the corresponding unrelated controls are 52.12% and 53.14%. Those subsets retain 841 and 2,257 original errors, so gallery composition matters.

The extra text direction after controlling for the noun midpoint reduces held-class squared error for drawing → photo by −0.0006% and +0.0617%. On actual misranked candidates it increases error by 0.214% and 0.344%. The direct language-direction hypothesis does not meet the registered criterion. The controlled grayscale → RGB comparison improves squared error by 0.038% and 0.057% and both class bootstrap intervals include zero. The linguistic change is therefore not selected as a retrieval algorithm, irrespective of TU results.

Freeze the interpretation and all settings now. On all 30 TU-Berlin unseen classes run the same class-level evidence test and the locked Ext-1 text regression with no target refit in the transfer row. Unlike Sketchy, the photo and sketch sets are unpaired. Use differences between class means for the natural shift. The controlled grayscale → RGB shift remains exactly paired per photograph. For the crossed-choice test use every sketch and every candidate, and report individual sketches with equal weight within class since source redraw IDs are not available. Each comparator sketch of the rival class is a different observation. On each error compare real rival sketches to equally weighted unrelated classes, holding both candidates fixed. Positivity of that contrast is the prediction. There is no dataset-specific threshold or choice of ranker. A TU result qualifies these two hypotheses only for transfer between two sketch/photo benchmarks.

The native pair test remains diagnostic and has access to annotated opposing sketches. It is not a single-query method. A deployable candidate will need evidence that this decision contrast can be identified from independent inputs allowed at inference. Recovering the cancellation algebra alone has direct prior art in [Winoground](https://arxiv.org/abs/2204.03162) and in a recent [preprint on paired CLIP scores](https://arxiv.org/abs/2611.30538).
