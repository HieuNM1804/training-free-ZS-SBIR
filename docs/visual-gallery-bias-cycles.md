# Can a single offset for each gallery item fix the observed binary ranking errors?

The two-query matching task cancels a separate score bias for each image. High matching accuracy does not guarantee that a single query-independent correction could repair even the original wrong pairs. The earlier report gave a three-class counterexample. Here test the obstruction on actual errors on both full Sketchy splits. [Earlier matching study and counterexample](results/native-choice-domain-contrast/README.md)

For each query take its highest-scoring true-class photo (exclude the actual photo it was drawn from) and highest-scoring wrong-class photo. If the wrong photo wins strictly, a correction must raise the true photo's offset above the wrong photo's by more than their original positive margin. Represent this as a directed edge from the wrong to the true photo. Check three families of permissible offsets, one per gallery photo, per photo-nominated public noun, or per true class. The latter is a label-informed diagnostic and not usable in deployment. Measure both single-view native visual cosine and the existing two-view Semantic Dot.

A directed cycle of strict error constraints cannot be repaired in full: the positive margins sum to more than zero while the offsets around the cycle telescope to zero. For this selected set of wrong pairs, any acyclic subset is feasible if offset magnitudes are unconstrained. Assign increasing offsets in topological order, with stride larger than the largest observed margin. Report the number of edges belonging to any cycle separately from a rigorous lower bound on the number that must remain wrong. Obtain the lower bound by packing query-edge-disjoint cycles, including self-loops and reciprocal pairs first. For an upper bound give an explicit vertex ordering, assign increasing offsets, and count violated inequalities. Verify every witness, edge, positive margin, ordering and bound. Derivations do not assume that two-cycles are the only obstruction.

These bounds concern just one originally wrong pair per affected query. Other gallery items and initially correct queries may introduce additional obstructions. A per-photo bias potentially depends on the whole unlabeled gallery; the best ordering in this oracle diagnosis uses the true classes and has no inference claim. Include class-level and photo-level cases, so a failure of a coarse grouping cannot be misreported as a failure of all possible single-photo biases. The underlying idea of supporting a matching by prices has a long history.
