# Does adding truthful context hide a detail visible in a drawing and a photograph?

This is an error diagnosis of frozen OpenAI CLIP ViT-B/32. A pair of predicates describes opposite visual states within one class. The prediction under test is that CLIP can distinguish visually confirmed states in isolation but loses that discrimination when both alternatives receive the same truthful context. Results operate on observed attributes, not on official category relevance. Keep the registered Semantic Dot and WordNet retrieval scores separate.

## Selection and observation before any model scores

Select eight classes per Sketchy split by SHA-256 with seed 42, skipping classes already used on the other split. Remove all source, positive and rival photos of the earlier 24-case visual inspection. Within each class take 16 unique source photos by hash. Select one real sketch per source by hash. The first six subjects per class constitute discovery, the last ten form the confirmation panel. Select all subjects before reading any model responses. No classes or examples are substituted for lack of a visible cue.

On discovery boards view the six sketch/source pairs per class and specify one proposition pair, plus a shared true description of the class without the tested detail. Favor physical relations, posture, shape, quantity and viewpoint; exclude absolute left/right and color-only attributes. Record classes without an observable varying cue. Freeze all descriptions in Git before opening the confirmation boards. One AI reviewer then annotates every confirmation image as A, B or unclear. Independently shuffle photo and sketch columns and hide their pairing. Record both label sets in Git before text encoding or accessing the pairing key. Same reviewer in both modalities and any subjective decisions limit generalization.

## Fixed readouts

Use identical texts for both modalities. Compare the two predicate sentences alone, each with the class-context sentence placed before it, and each with that context after it. A neutral image-description sentence of similar word count is a length control. The natural class context must be compatible with both test states. No prompt or ordering is selected using results. Report the two true-context orders separately and their equally weighted metric average. For each image the signed response is its normalized visual embedding dotted with the difference of the two normalized text embeddings. Use the stored original view for both domains; additionally check the standard two-view sketch on these mirror-invariant properties.

Primary population is the set of confirmation subjects assigned the **same definite state in both depictions**. Within each class compare the margin for every state-A subject against every state-B subject and award half credit to ties. This is AUC and cancels a constant preference for one sentence. Macro-average classes with at least one subject in each state. Publish denominators and class results. Other readouts are balanced accuracy when choosing a sentence for one image, the proportion of A/B pairs in which both decisions are correct, and the same comparisons on all clearly annotated images in each modality irrespective of paired agreement. A weak or opposite contextual effect, too few eligible classes, or a deterioration reproduced by neutral padding weakens the proposed specific failure. Do not infer a category mAP gain or a new retrieval method from these diagnostics.

To connect to retrieval while holding both the query and the candidate set fixed, let each sketch choose A or B using its two caption scores and then use the chosen text as a query to rank *two photographs of different subjects and opposite visible states within the same class*. Exclude the sketch's source photo. Compare the selected-description rule and the best readout with the sketch's actual state supplied retrospectively. Report class-balanced two-photo accuracy separately from category mAP. This tests whether any nomination errors matter when text is used as the retrieval query. A cross-domain class transfer claim needs separate evidence.
