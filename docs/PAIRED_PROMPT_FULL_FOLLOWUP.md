# Full evaluation of the sign of the image-specific edit

Reducing the cross-prompt variance of held-out names changed balanced Sketchy mAP by only +0.008 points. The sign-reversed control improved Ext-1 and nearly tied the base on Ext-2. On Ext-1 misses with a literal public category name, 83 names moved down and 38 moved up after the variance-reducing intervention. These outcomes motivate an exploratory follow-up that asks whether depicting an object as a sketch makes some *correct* distinctions more pronounced. Its primary is the sign-reversed head edit. The observed pilot results motivated the choice of this sign.

Build one common configuration pool from the top three sign-reversed pilot settings, two variance-reducing settings, and the best settings for the text, rotation, cross-fold and exchanged-noun controls. The union also applies to every control in the full sweep. Include the positive and negative versions of each head, textual-subspace, rotated-subspace, noun-exchange and unshrunk transformation. Add a particularly important simple comparator that moves word scores in the same direction by extrapolating the text prompt away from the midpoint at four strengths. Allow the original regional retrieval result as a fixed choice.

The decision criterion uses all 14,179 and 12,694 Sketchy queries at their original sample weights, averaging the two mAP scores, then using precision to break ties. A frozen audit replays the selected permutations through original KD-SBIR code, including against independently optimized negative textual extrapolation, direction-reducing and simplified controls. TU-Berlin retrieval uses the resulting locked configuration for all 30 classes. Both benchmarks share one direction of domain conversion.
