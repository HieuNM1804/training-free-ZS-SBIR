# Cross-domain retrieval from paired saliency and appearance

Both query and gallery use the same frequency-tuned Lab saliency map, adaptive threshold, crop size, border handling and positive/negative saliency views. A constant image falls back to the full field. The color of any padding is measured on the image perimeter. All input images are encoded using the same frozen OpenAI CLIP ViT-B/32. Each query can be processed alone.

The first research question is whether affine coordinates in an image's own saliency representation can locate nearby target-domain colors and semantics without paired examples across datasets. Each gallery image supplies its own two representations. The image-only arm reads out the original target image embeddings. The public-vocabulary arm can also express an image as a combination of target-domain concept prompts, then carry the same coefficients to their source-domain counterparts. The cross-domain pairing is constructed at indexing time. An unchanged full-frame version and a permuted pairing measure the contributions of foreground localization and the actual image-to-image correspondence.

Three papers contribute mechanisms. The implementation uses the smoothed Lab distance to global mean and adaptive threshold from frequency-tuned saliency, the affine coordinate transfer from neighbor embedding, and the neighborhood agreement and graph fusion from Query Specific Fusion. It operates in the native CLIP embedding space. [Achanta et al., CVPR 2009](https://ivrlwww.epfl.ch/supplementary_material/RK_CVPR09/) · [Chang et al., CVPR 2004](https://cse.hkust.edu.hk/~dyyeung/paper/pdf/yeung.cvpr2004.pdf) · [Zhang et al., ECCV 2012](https://link.springer.com/chapter/10.1007/978-3-642-33709-3_47)

The first grid and the adaptive refinement use both Sketchy splits. Precision has priority and the splits have equal weight. Each arm's best setting determines the location of the fine grid. Its final winner and predeclared controls are locked before any TU scores from this method are computed. The verifier requires every one of the 30 official TU-Berlin categories in both query and gallery.
