# Does the existing neighbor average preserve evidence for the particular subject?

This is a diagnostic of the already reported 64-donor index. It adds no method to the baseline. Freeze the same construction for both exploratory Sketchy splits and the 30-class TU check before viewing these results. Seed 42, Kaggle, frozen OpenAI CLIP ViT-B/32, fixed 601-word dictionary and original KD evaluator. No optimization, gradient, edge detector, or score blending. No query sees another sketch during retrieval.

The photo word vector p is a deterministic function of its stored normalized RGB embedding v, the fixed text bank and CLIP temperature. Smoothing it over other images changes which images contribute evidence for the candidate. It estimates a local average across depictions/subjects. There is no independent measurement noise in p conditional on that exact v.

## Primary retrieval and held-out donors

Replay the native semantic P and WP on every official query and gallery, where W averages 64 other photos selected by the original RGB cosine graph. As a modality control apply exactly the same W to native unit visual embeddings and use the ordinary normalized two-view sketch readout; do not normalize the averaged donor vectors. These are averages of the existing scalar scores. Different native versus semantic gains describe dependence on the readout, including the different starting levels.

Also partition the gallery into two donor banks using only a hash of the dataset, original gallery ID and seed. Independently recompute the same 64-neighbor rule using each bank as the only possible donor pool for all candidates, excluding self. Evaluate the complete gallery in both cases. On Sketchy use the bank that omits the query's source photo to read the corresponding evaluation row. No competing candidate in that row has access to that photo, and every original gallery candidate is still scored. The source ID enters only to choose the retrospective arm. The unpaired natural queries in TU use the mean of the two full-gallery evaluations. This control also reduces the size of the donor pool. Compare with full 64 to disclose this change.

## Evidence for an individual subject

Use every human drawing with its documented source photo on Sketchy. TU has no such pairing. As a separate physical control on all three galleries, encode a grayscale copy of every photo and ask it to retrieve its own original RGB image. Grayscale and RGB word vectors both use the fixed photo template. Under the source-withheld construction, report the source's within-class top-1 and reciprocal rank against every photo of that class. Break exact score ties by the mean reciprocal rank and mean top-1 success over the tied ranks. Keep category mAP/P and the instance metrics separate. Their magnitudes are not comparable.

For an additional rank contrast, take two different source identities i,j from the same class and the same withheld half. Compare the sum of the scores of their own sketches with the sum after exchanging the two gallery identities. Use all drawings with equal weight per source pair and per class. This comparison deliberately uses two independent sketches after the original scores have been calculated. It measures evidence for distinctions inside a class and never supplies a second sketch to a ranker.

Finally evaluate a conditional null on the already scored held-out subjects. Keep the full table of how many slots of each donor class each subject received. Within each target-class/donor-class block, permute donor endpoints among slots. This preserves each individual donor's total frequency within that block and the target's class counts; repeated donors in a row are allowed in this descriptive null. Its exact expected word or visual vector for a target can be computed from the pooled slot means. For source i, form the mean query of its own drawings minus the equally weighted mean for all other sources of the same class. Measure this contrast on P, WP and the expected null. The linear contrast on the null equals the expectation over shuffles. The ranking of that expectation is not an expected retrieval metric, so the null is used only for the linear contrast. Verify conservation of the total vector within each target class/fold. A positive real-minus-null contrast would locate subject evidence in the actual donor selection beyond class mixture. A decline relative to P would show that this evidence is partially lost by averaging even if category mAP improves.

For this linear contrast, restrict other sources to the same donor fold as the evaluated source. Weight folds by the number of distinct source pairs before averaging classes equally. Twice the source-average contrast is the mean correct-minus-exchanged score for two distinct subjects. A separate rank accuracy counts strict paired preferences and gives half credit for exact ties. Within-class source R@1 and MRR average drawings within each source, then sources within each class, then classes equally. Official category mAP/P retain the original query weighting.

The source-withheld comparison, the two-query contrast and the oracle null are diagnostics rather than alternative deployment algorithms. Confidence intervals are paired class bootstraps (10,000 resamples, seed 42), with all observed errors reported. Two Sketchy splits share classes and source images. TU addresses a dataset change in sketch → photo, while grayscale is a controlled photometric intervention and not a second artistic domain.
