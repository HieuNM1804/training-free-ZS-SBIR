# Terminal-state transport between two image depictions

The working hypothesis is that the change from drawing to photo in CLIP depends on what is depicted. Analysis on Sketchy grouped sketches by source photo, then split distinct source photos into two halves per category. The cross-half covariance of category displacements is 0.11725 on Ext-1 and 0.12495 on Ext-2. It accounts for 29.0% and 30.0% of the squared class-mean displacement respectively. Source identity and class annotations are used exclusively in retrospective diagnosis. A different hypothesis is that generic text residuals act on visual content in the correct direction. This one experiment tests that additional assumption.

## Representation and retrieval

OpenAI CLIP ViT-B/32 supplies both the image embeddings and two fixed contexts, "a drawing of an object." and "a photo of an object." The image state is carried backwards through the source context field, then forwards through the target context field. Retrieval uses the cosine of the transported sketch against each photo in a common one-dimension-reduced output space. The gallery can be embedded offline. The native sketch and its mirror each undergo the same independent map before averaging their unit outputs. The algorithm needs no query examples, word list, class names, gallery neighbors or learned parameters.

Write the frozen text readout as `(w γ + β)P` on a zero-mean terminal state w with squared norm d. With row vectors let A = diag(γ)P, let H subtract the coordinate mean, and let Π project away the row direction 1ᵀA. Define φ(u) = unit(Π[(√d u)A + βP]) for each centered unit u. The removed direction is where an unknown scalar feature mean would enter the linear readout. To invert the projected observation x, compute a = H(xA⁻¹), c = H(β/γ). Solve ||λa − c||² = d for its positive root and return u = (λa − c)/√d. There is exactly one positive root because ||c|| < √d for this checkpoint. The chart uses float64. The spherical readout is an idealization of the final normalization and is tested against the native projected terminal token.

Each frozen residual sublayer j supplies an increment f under its own fixed prefix. The field at u is the centered increment Hf(ru)/r projected onto the tangent plane perpendicular to u. The scale r is the norm of the centered terminal state at that same native sublayer and prefix. Causality allows prefix keys and values to be cached for the attention residual. Solving this smooth field for unit time per sublayer defines a flow F for each context. The proposed map is φ ∘ Fphoto ∘ Fdrawing⁻¹ ∘ φ⁻¹. Each layer's spherical flow is defined here. Its trajectory can differ from the pretrained discrete transformer update. Smoothness and reversibility establish a coordinate transform. Transfer of depicted content into photo coordinates is an empirical claim.

## Prior work and scientific distinction

- SEARLE maps an image into a pseudo-word, composes it with relative text, and uses textual inversion or a distilled mapping. Cross the Gap studies optimization-based modality inversion for within-modality retrieval. Here the inverse is closed-form at the final readout and reverses a constructed conditional flow over the terminal hidden state. [SEARLE, ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Baldrati_Zero-Shot_Composed_Image_Retrieval_with_Textual_Inversion_ICCV_2023_paper.html) · [Cross the Gap, ICLR 2025](https://arxiv.org/abs/2502.04263)
- Neural ODEs establish the continuous residual-dynamics formalism. FlowCIR learns a conditional transport field for composed retrieval, and ControlEmbed trains a text-conditioned affine transformation. The question here is whether the residual fields inside the original frozen CLIP text encoder already contain usable depiction-change dynamics. [Neural ODEs, NeurIPS 2018](https://arxiv.org/abs/1806.07366) · [FlowCIR, ECCV 2026](https://arxiv.org/abs/2607.02284) · [ControlEmbed, ECCV 2026](https://joefioresi718.github.io/ControlEmbed_webpage/)
- FreeDom, BASIC and STiTch motivated examining how composed retrieval extracts transferable signals from a frozen vision-language space. They respectively use discrete language and database expansion, visual and textual scoring, and caption refinement with set alignment. These operations are absent from the proposed map. [FreeDom](https://arxiv.org/abs/2412.03297) · [BASIC](https://papers.neurips.cc/paper_files/paper/2025/hash/6391a02f02dc529cfa3f242fb4343c6a-Abstract-Conference.html) · [STiTch](https://arxiv.org/abs/2605.21261)

## Fixed experiment

The three tail depths are 1, 3 and 6. The numerical step count for each depth is chosen exclusively by a label-free round-trip and step-doubling gate on 48 Ext-1 inputs. Each depth must pass. Select depth by equally weighted full-unseen Sketchy mAP, breaking ties with mean precision, then shallower depth. Freeze before TU-Berlin. Report native visual cosine, the projected identity, a fixed displacement between the same prompts, and the archived paired Semantic Dot comparator. Each main rank is replayed by the original KD-SBIR evaluator. Test content dependence against the actual displacement of other source identities of the same class. The requested target is +4 absolute mAP on each Sketchy split, positive transfer to TU and evidence supporting the proposed mechanism. Stop following a negative outcome. The numerical specification and artifact hashes are recorded before scoring.

On the authorized offline Kaggle layout run `python -m tf_sbir.run_depiction_flow <git-commit>` at the checkout root. The existing frozen-unseen manifest supplies the exact CLIP checkpoint and visual features.
