# How much must a ranking change under alternative wordings of a domain?

A fixed correction to CLIP's depiction prompt improved metrics on exploratory Sketchy but reduced performance on TU-Berlin. One possible explanation is that the correction treats the way the source domain is named as certain. The tested hypothesis is that a correction should make the smallest information change required by two legitimate descriptions of the same domain. This is not a bound on ground-truth class relevance. Both endpoints can share an error.

Use the same two established source descriptions “drawing” and “sketch”. Cross each with the indefinite and definite articles from the original templates. Encode the corresponding photo prompts with the same two articles. For each name use the normalized sum across articles in each group. Every public name appears in every template. The unedited global word and region scores are those of the frozen reference method. Each of the two source-to-photo prompt gaps now predicts its own correction to an individual view's word distribution. A scalar controls the sign and magnitude of this common type of intervention. No information from another sketch is required.

Let p0 be the original distribution and pA,pB the corrected distributions for the two source descriptions. At each coordinate let L and U be the smaller and larger of their probabilities. The set of probability vectors with L ≤ p ≤ U contains both descriptions and every shared mixture of them. Among all distributions in this set, choose the one closest in forward KL to p0. It has p_i = clip(c p0_i, L_i, U_i), with the single scale c chosen to make the probabilities sum to one. This follows from the one simplex Lagrange multiplier. Identical endpoints return that one endpoint. If p0 already satisfies the bounds, it is unchanged. The interval constraints permit different coordinates to approach different endpoints and thus form a relaxation of a single unknown common mixture.

The same mathematical intervention can act in the vocabulary or over candidate photos. In vocabulary space the posterior contains the gallery marginal of the name, and we restore the original total likelihood of each view when mapping back to the word readout. In photo space we build both full candidate rank scores and normalize them over the actual gallery. Intervene at the global branch, the local branch or their fixed combination. Choose the place and strength on the two complete exploratory Sketchy splits if a pilot warrants expansion, and freeze the choice before TU-Berlin.

Compare with a shared arithmetic mixture of the two endpoint distributions, the closest one-parameter convex mixture by KL, and either endpoint. Include geometric interpolation between p0 and the mean at exactly the same KL distance as our projection. The last control tests whether conservative step size alone accounts for the gain. As a falsifier permute the relative interval widths within blocks of similar baseline probability while preserving the same feasible central distribution. Include signed extrapolation of the original averaged template embeddings. Record feasibility, KL matching, per-query corrections and regressions. Closed-form conditional optimization of posterior distributions was used in statistical language alignment. The new claim under test is inference-time uncertainty in which public description of an image domain to trust, with a measurable effect on lexical and photo retrieval probabilities.
