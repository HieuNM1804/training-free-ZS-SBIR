# Can perfect word-sense resolution rescue the public nouns that CLIP nominates?

The name-swap pilot evaluated two nominated definitions. A low ceiling for those two definitions could arise from proposing the wrong object words or from choosing the wrong meanings of otherwise useful words. The distinction matters before designing any mechanism for retrieving across depictions. The experiment uses the existing 1,135 WordNet senses mapped to 512 distinct Open Images names. It is an upper-bound diagnostic, using the true class when looking up utility. No new search system or tuning on a held-out dataset is involved.

The primary test gives the selector all senses of the first **two distinct public nouns** nominated by the sketch. For each query use the exact archived canonical-sentence AP and precision measured against all unseen RGB photos by the original KD evaluator. Record (i) the utility of the actual first sense, (ii) the better of the actual two nominated senses, (iii) the best sense of the first noun, and (iv) the best sense across the two nouns. AP and precision ceilings are separate. Measure paired effects with equal weight per query and with equal weight per subject then class, using the existing seed-42 paired class bootstrap. Repeat the comparison on the source photograph with the identical drawing prompt and one view. Include one sketch view and the original two-view sketch endpoint.

For context compute the complete cumulative oracle curve for every possible noun-prefix length, giving each included noun **every** meaning. Rank each nominatable public noun by the highest observer cosine of its canonically assigned sense descriptions, preserving the pilot's nomination rule. Recover stable tie order using the original sense bank. Use the archived first two senses and their noun order in case of numerical ties on the replacement session. Rank the remaining nouns after removing those two. Verify agreement and the full-bank ceiling. Also compute the expected ceiling for a uniformly random list of distinct nouns analytically. This accounts for the fact that any list has an increasing oracle ceiling with length. The reported crossings are the earliest fixed budgets reaching the already published Semantic Dot mAP and +4 or +5 absolute points in this optimistic procedure. They are a property of the curve, not a chosen deployment budget. Each split uses its own fixed gallery and official metric.

If the two-noun oracle fails to reach the target on either split, resolving polysemy inside these nominees alone cannot meet the stated goal on both splits. A high ceiling with a longer list establishes opportunity, not a way to select the winning meaning without class labels. Natural source photos, class information and oracle sense selection are available only to the diagnosis.

The preflight inventory check found that 512 public names occur in the dictionary but only 508 ever serve as a synset's canonical head in the original pilot. Four names occur only as aliases of a shared sense. The complete prefix and its random control therefore use the 508 nominatable heads in the existing algorithm. Each nominated noun's ceiling includes **all** senses attached to its public ID, also when it is an alias of a different canonical head. This correction was recorded before observing scores.
